Урок Python

Чому не черепашка?

Черепашка вміє малювати. Але посунути намальоване — ні.

Черепашка

малює рухом: іде й лишає слід

намальоване — просто пікселі

посунути квадрат? Тільки стерти все й перемалювати

Полотно

ставить фігуру одразу цілою

кожна фігура запам’ятовується

її можна посунути, перефарбувати, стерти

Полотно — основа для анімації та ігор. Сьогодні вчимося на ньому малювати.
