Як дізнатися тип?

Python визначає тип сам, за значенням. Команда type() його показує.

print(type(5))
print(type(2.5))
print(type("5"))
print(type(True))

<class 'str'>

Урок Python

Тип bool: лише два значення

True

False

Пишуться англійською, з великої літери. Виглядає бідно, а на цьому тримаються всі рішення програми: чи правильний пароль, чи вистачає грошей.

Знак

Значення

>

більше

<

менше

>=

більше або дорівнює

<=

менше або дорівнює

==

дорівнює

!=

не дорівнює

Порівняння завжди дає True або False

print(5 > 3)    # True
print(4 != 4)   # False

Урок Python

одна риска — одна дія

==

дві риски — питання

Запам’ятайте: одна риска кладе, дві питають.

Урок Python

Скільки буде 0.1 + 0.2?

Комп’ютер зберігає дроби у двійковій системі, а 0.1 там нескінченний, як 1/3 у десятковій. Тому гроші часто зберігають у копійках цілим числом.

0.30000000000000004

саме це виведе Python
