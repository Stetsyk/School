## 2. Пояснення (8-10 хв)

### Блок 1. Готові команди

Для найчастіших задач у Python уже є готові команди.

```
оцінки = [10, 7, 11, 9, 12]
print(sum(оцінки))       → 49     сума всіх
print(max(оцінки))       → 12     найбільший
print(min(оцінки))       → 7      найменший
print(len(оцінки))       → 5      кількість
```

І два методи, які пишуть через крапку:

```
print(оцінки.count(10))   → 1     скільки разів трапляється 10
print(оцінки.index(11))   → 2     на якому місці стоїть 11
```

Середнє з готової команди не існує, але воно робиться в один рядок: `sum(оцінки) / len(оцінки)`.

> 📝 **Готові команди для списків:**
>
> | Команда | Що робить |
> | --- | --- |
> | `sum(список)` | сума всіх елементів |
> | `max(список)` | найбільший елемент |
> | `min(список)` | найменший елемент |
> | `len(список)` | кількість елементів |
> | `список.count(x)` | скільки разів трапляється `x` |
> | `список.index(x)` | індекс першого входження `x` |

> ❓ **Як одним рядком порахувати середній бал списку `оцінки`?**
>
> *Очікуємо:* `sum(оцінки) / len(оцінки)`.

### Блок 2. Пошук за умовою

Готові команди покривають прості випадки. Але щойно з'являється умова, потрібен цикл.

Наприклад, порахувати, скільки в списку оцінок вищих за 9. Це лічильник за умовою з уроку 20, тільки тепер він іде по списку:

```
кількість = 0
for оцінка in оцінки:
    if оцінка > 9:
        кількість += 1
print("Оцінок вище 9:", кількість)
```

Так само рахують суму лише підхожих значень — змінюється лише те, що додається.

> 📝 **Підрахунок за умовою:**
>
> ```
> кількість = 0
> for елемент in список:
>     if умова:
>         кількість += 1
> ```
>
> Збільшення лічильника стоїть **усередині `if`**.

> ❓ **Що зміниться в цій програмі, щоб рахувати не кількість, а суму таких оцінок?**
>
> *Очікуємо:* замість `кількість += 1` треба `сума += оцінка`.

### Блок 3. Відбір у новий список

Найкорисніший прийом теми. Якщо потрібні не лише кількість, а самі відібрані значення — їх збирають у **новий** список.

```
оцінки = [10, 7, 11, 9, 12, 5]
високі = []
for оцінка in оцінки:
    if оцінка > 9:
        високі.append(оцінка)
print(високі)      → [10, 11, 12]
```

Схема така сама, як у накопичувача: створити порожній список до циклу, наповнювати всередині, використовувати після.

Головна перевага цього прийому в тому, що початковий список не змінюється — з ним і далі можна працювати. І він розв'язує проблему, про яку ми говорили на уроці 25: видаляти елементи прямо під час перебору небезпечно, а зібрати потрібні в новий список — цілком безпечно.

> 📝 **Відбір у новий список:**
>
> ```
> відібрані = []
> for елемент in список:
>     if умова:
>         відібрані.append(елемент)
> ```
>
> Початковий список при цьому не змінюється.

> ❓ **Де створюють порожній список для відбору?**
>
> *Очікуємо:* до циклу, один раз.

### Блок 4. Пошук найбільшого вручну

Готовий `max` є, але корисно розуміти, як він працює всередині. Це той самий прийом із лідером, що на уроці 20, тільки початкове значення тепер беруть із самого списку:

```
найбільша = оцінки[0]
for оцінка in оцінки:
    if оцінка > найбільша:
        найбільша = оцінка
```

Тепер немає проблеми з від'ємними числами: за початкового лідера взято перший елемент, а він точно є серед даних.

Це знадобиться там, де готова команда не працює: наприклад, коли треба знайти не саме значення, а його **позицію** в списку.

```
найкраща = оцінки[0]
номер = 0
for i in range(len(оцінки)):
    if оцінки[i] > найкраща:
        найкраща = оцінки[i]
        номер = i
print(f"Найкраща оцінка {найкраща} стоїть на місці {номер + 1}")
```

> 📝 **Пошук найбільшого вручну:** за початкового лідера беруть **перший елемент списку**, потім порівнюють із ним решту.
> Якщо потрібна ще й позиція — перебирають індекси й запам'ятовують номер.

> ❓ **Чому за початкового лідера краще брати перший елемент, а не нуль?**
>
> *Очікуємо:* нуля може не бути серед даних, і для від'ємних чисел відповідь буде неправильна.

**Бонус 4.** Знайдіть **позицію** найбільшого елемента, а не саме значення. Що робити, якщо найбільших кілька?

#### ✅ Відповіді до бонусів

**Бонус 1.**
```
імена = ["Оля", "Володимир", "Іван", "Катерина"]
найдовше = імена[0]
for ім'я in імена:
    if len(ім'я) > len(найдовше):
        найдовше = ім'я
print(найдовше)
```
Головна ідея: порівнюємо не самі значення, а результат обчислення над ними. Готовий `max` тут не підійде, бо він порівняв би імена за абеткою.

**Бонус 2.**
```
числа = [4, -2, 7, -9, 0, 3]
додатні = []
відємні = []
for n in числа:
    if n > 0:
        додатні.append(n)
    elif n < 0:
        відємні.append(n)
```
Тут важливий `elif` замість другого `if`: нуль не потрапляє в жоден зі списків, і це правильно.

**Бонус 3.** Два проходи: спершу треба дізнатися середнє, і лише потім відбирати.
```
оцінки = [10, 7, 11, 9, 12, 4]
середнє = sum(оцінки) / len(оцінки)
кращі = []
for о in оцінки:
    if о > середнє:
        кращі.append(о)
print(середнє, кращі)
```
Середнє тут 8.83, тому в новий список потраплять 10, 11, 12 і 9.

**Бонус 4.** Разом із лідером запам'ятовують його номер:
```
числа = [7, 12, 9, 12, 4]
поз = 0
for i in range(len(числа)):
    if числа[i] > числа[поз]:
        поз = i
print(поз)
```
Виведе `1` — позицію **першого** з найбільших, бо умова строга `>`. Якщо потрібен останній, беруть `>=`. Якщо потрібні всі позиції, їх збирають у список другим проходом. Готова команда `числа.index(max(числа))` робить те саме, але теж повертає лише перше входження.

## 7. Якщо лишився час

**Чому вміти вручну все-таки потрібно.** Готова команда `max` знаходить найбільше число. Але щойно задача трохи змінюється — знайти найдовше слово, найкращого учня за середнім балом, найдорожчий товар зі знижкою — готової команди вже немає. Цикл же працює завжди, треба лише правильно записати умову. Саме тому в бонусі 1 `max` не допоміг.

**Скільки кроків робить пошук.** Щоб знайти найбільше число в списку зі ста елементів, треба переглянути всі сто — інакше можна пропустити потрібне. Це називають лінійним пошуком, і швидше в невпорядкованому списку не буває. Але якщо список **упорядкований**, працює двійковий пошук із уроку 23, і ста елементів вистачить сім кроків. Саме тому дані так часто тримають відсортованими — про сортування наступного уроку.
