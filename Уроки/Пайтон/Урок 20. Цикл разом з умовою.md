## 1. Вступ-гачок (2-3 хв)

Уявіть, що вам дали пачку з тридцяти контрольних робіт і просять сказати три речі: скільки робіт написано на високий бал, яка найкраща оцінка і хто її отримав.

Що ви робите? Берете роботи по одній. Дивитеся оцінку. Якщо висока — ставите риску на полях. Якщо вона більша за всі попередні — запам'ятовуєте. І так до кінця пачки.

Це і є цикл із умовою всередині. Перебираємо все підряд, але дію виконуємо не завжди, а тільки коли значення підходить.

Сьогодні навчимо цього програму. Це поєднання двох тем, які ми вже знаємо окремо, і саме воно робить цикли по-справжньому корисними.

## 2. Пояснення (8-10 хв)

### Блок 1. if усередині циклу

Розгалуження можна поставити прямо в тіло циклу. Тоді умова перевіряється **на кожному кроці** заново.

```
for i in range(1, 11):
    if i % 2 == 0:
        print(i, "парне")
```

Цикл пройде всі числа від 1 до 10, але виведе лише парні.

Зверніть увагу на відступи. Їх тут **два рівні**: `if` з одним відступом, бо він у тілі циклу, а `print` із двома, бо він у тілі `if`.

> 📝 **Розгалуження в тілі циклу** перевіряється на кожному кроці заново.
> Відступів тут два рівні: `if` усередині циклу, дія — усередині `if`.

> ❓ **Скільки разів перевіриться умова в циклі `for i in range(100)` з одним `if` усередині?**
>
> *Очікуємо:* сто разів, по одному на кожному кроці.

### Блок 2. Лічильник за умовою

Тепер поєднаємо це з накопичувачем з минулого уроку. Якщо збільшувати лічильник не завжди, а тільки за умовою, отримаємо підрахунок кількості.

```
кількість = 0
for i in range(1, 101):
    if i % 7 == 0:
        кількість += 1
print("Чисел, кратних 7:", кількість)
```

Схема та сама, що вчора, з однією зміною: `кількість += 1` стоїть усередині `if`, а не просто в тілі циклу.

Так само можна накопичувати й суму — тільки тих значень, що підходять:

```
сума = 0
for i in range(1, 101):
    if i % 2 == 0:
        сума += i
```

> 📝 **Лічильник за умовою:** обнулити до циклу → перевірити умову в тілі → збільшити лічильник **усередині `if`**.
> Якщо `+= 1` поставити поза `if`, порахуються всі значення, а не лише підхожі.

> ❓ **Що станеться, якщо `кількість += 1` вийняти з-під `if` і лишити просто в тілі циклу?**
>
> *Очікуємо:* порахуються всі числа підряд, а не лише ті, що підходять під умову.

### Блок 3. Пошук найбільшого

Класична задача: серед багатьох значень знайти найбільше. Прийом такий самий, як із контрольними роботами.

Заводимо змінну для лідера. Порівнюємо з нею кожне наступне значення. Якщо нове більше — воно стає новим лідером.

```
найбільше = 0
for i in range(5):
    n = int(input("Введіть число: "))
    if n > найбільше:
        найбільше = n
print("Найбільше:", найбільше)
```

Тут є пастка. Початкове значення `найбільше = 0` працює тільки якщо всі числа додатні. Якщо ввести п'ять від'ємних, програма видасть нуль — а такого числа взагалі не вводили.

Надійніший спосіб — узяти за початкового лідера **перше введене число**, а порівнювати з ним решту.

> 📝 **Пошук найбільшого:** завести змінну-лідера → на кожному кроці порівняти з нею нове значення → якщо нове більше, воно стає лідером.
> Початкове значення лідера краще брати з перших даних, а не з нуля.

> ❓ **Чому `найбільше = 0` небезпечно як початкове значення?**
>
> *Очікуємо:* якщо всі значення від'ємні, програма поверне нуль, якого серед них немає.

### Блок 4. Знайомство: готові дані у квадратних дужках

Щоразу вводити сім чисел через `input` нудно, а справжні дані — погода за тиждень, оцінки в журналі, кроки з телефона — зазвичай уже десь записані. Сьогодні ми трохи підглянемо в тему уроку 24 і будемо брати дані з готового **списку**.

```
температури = [4, -2, 6, 0, -5, 8, 3]
print(температури[0])     → 4
print(температури[1])     → -2
print(температури[6])     → 3
```

Список — це ряд пронумерованих комірок. Номер комірки пишуть у квадратних дужках, і він називається **індексом**. Рахунок починається з нуля — так само, як у `range`.

Саме тому список і `range` чудово працюють разом. Змінна циклу `i` по черзі стає 0, 1, 2… і на кожному кроці ми беремо комірку з цим номером:

```
for i in range(7):
    if температури[i] < 0:
        print("Мороз:", температури[i])
```

Якщо є два списки однакової довжини, однаковий індекс зв'язує їх між собою: `дні[i]` і `температури[i]` — це назва дня і температура того самого дня.

```
дні = ["пн", "вт", "ср", "чт", "пт", "сб", "нд"]
for i in range(7):
    if температури[i] < 0:
        print(дні[i], "мороз", температури[i])
```

Поки що нам вистачить лише читати зі списку. Як створювати, змінювати й доповнювати списки — розберемо на уроці 24.

> 📝 **Готовий список:** `дані = [4, -2, 6]` · `дані[0]` — перше значення, `дані[2]` — третє.
> Перебір: `for i in range(кількість):` і в тілі `дані[i]`.
> Однаковий `i` у двох списках — це дані про одне й те саме.

> ❓ **Що виведе `print(температури[4])` для списку вище?**
>
> *Очікуємо:* −5, бо це п'ята комірка, а її номер 4.

**🔌 Завдання 2 — відповіді:** бракує у вівторок 1500, у п'ятницю 3700, у суботу 100 · ціль виконано 4 дні · за тиждень 58400 кроків.
Зразок тіла циклу:
```
for i in range(7):
    if кроки[i] >= ціль:
        print(дні[i], "— ціль виконано ✅")
        виконано += 1
    else:
```

## 5. ⭐ Бонус для сильних

**Бонус 1.** Напишіть програму, яка виводить усі прості числа від 2 до 50. Просте число ділиться без остачі тільки на 1 і на себе.

**Бонус 2.** Виправте програму пошуку найбільшого так, щоб вона правильно працювала й для від'ємних чисел.

**Бонус 3. Різке потепління.** Візьміть списки погоди із завдання 1. Виведіть дні, коли стало тепліше **більш ніж на 4°** порівняно з учорашнім днем, і на скільки саме. Підказка: учорашня температура — це сусідня комірка ліворуч, тобто `температури[i - 1]`. Подумайте, з якого `i` має починатися цикл і чому.

**Бонус 4. Два рекорди.** Знайдіть у списку кроків із завдання 2 **найбільше й друге за величиною** значення за один прохід циклом. Двічі перебирати не можна, і сортувати теж.

#### ✅ Відповіді до бонусів

**Бонус 1.** потрібен цикл усередині циклу, і це тема уроку 22. Проста ідея така: для кожного числа перевіряємо всі можливі дільники й рахуємо, скільки їх знайшлося.
```
for n in range(2, 51):
    дільників = 0
    for d in range(2, n):
        if n % d == 0:
            дільників += 1
    if дільників == 0:
        print(n)
```

**Бонус 2.** перше число беремо за лідера до циклу, а порівнюємо решту.
```
найбільше = int(input("Число 1: "))
for i in range(4):
    n = int(input("Наступне число: "))
    if n > найбільше:
        найбільше = n
print(найбільше)
```

**Бонус 3.** Середа (+8) і субота (+13).
```
for i in range(1, 7):
    різниця = температури[i] - температури[i - 1]
    if різниця > 4:
        print(дні[i], "потепліло на", різниця)
```
Цикл починається з 1, бо в понеділка немає «вчора» в нашому списку. Найцікавіше — що станеться, якщо почати з 0: помилки не буде! `температури[-1]` у Python означає останню комірку, тобто неділю, і програма мовчки порівняє понеділок із неділею. Від'ємні індекси розберемо на уроці 24, а тут це гарний приклад, що програма без помилок — ще не правильна програма.

**Бонус 4.** 12400 і 10100. Потрібні два лідери, і оновлювати їх треба в правильному порядку.
```
перше = 0
друге = 0
for i in range(7):
    if кроки[i] > перше:
        друге = перше
        перше = кроки[i]
    elif кроки[i] > друге:
        друге = кроки[i]
print(перше, друге)
```
Головна ідея в рядку `друге = перше`: старий лідер не зникає, а спускається на друге місце. Якщо переставити ці два рядки місцями, обидві змінні стануть однаковими.

## 7. Якщо лишився час

**Скільки перевірок робить ваш телефон щосекунди.** Кожен кадр гри, кожне оновлення екрана — це тисячі циклів із умовами всередині. Перевірити, чи торкнувся палець кнопки. Чи вийшов персонаж за межі. Чи перетнулися два об'єкти. У сучасній грі таких перевірок буває більше мільйона за секунду, і всі вони влаштовані рівно так, як те, що ви написали сьогодні.

**Прийом із лідером має назву.** У програмуванні його називають лінійним пошуком максимуму, і він цікавий тим, що працює за один прохід: кожне значення переглядається рівно раз. Швидше за це в загальному випадку не буває — щоб точно знайти найбільше, треба хоча б подивитися на кожне число.
