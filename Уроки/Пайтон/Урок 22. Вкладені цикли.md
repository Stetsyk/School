## 1. Вступ-гачок (2-3 хв)

Подивіться на звичайну таблицю множення. Десять рядків, у кожному десять стовпців, разом сто добутків.

Як її вивести? Один цикл дає рядок чисел. Але нам треба, щоб цих рядків було десять — і кожен зі своїми числами.

Тобто повторити треба саме повторення.

Так само влаштована ваша шкільна ситуація: у тижні п'ять днів, у кожному дні шість уроків. Щоб перерахувати всі уроки тижня, ви подумки берете день і проходите всі його уроки, потім наступний день і знову всі уроки.

Це і є вкладені цикли. Сьогодні розберемось, як вони працюють, і намалюємо кілька речей, які без них зробити неможливо.

## 2. Пояснення (8-10 хв)

### Блок 1. Цикл усередині циклу

Один цикл ставлять у тіло іншого — з додатковим відступом.

```
for i in range(3):
    for j in range(2):
        print(i, j)
```

Виведе шість рядків:
```
0 0
0 1
1 0
1 1
2 0
2 1
```

Зовнішній цикл із змінною `i` робить три кроки. На **кожному** з них внутрішній цикл із змінною `j` відпрацьовує повністю, від початку до кінця.

Тому загальна кількість повторень — це добуток: три на два дорівнює шість.

Змінні мають бути **різні**. Якщо обидва цикли назвати `i`, внутрішній зіпсує лічильник зовнішнього.

> 📝 **Вкладений цикл** — цикл у тілі іншого циклу.
> Внутрішній цикл **повністю відпрацьовує** на кожному кроці зовнішнього.
> Кількість повторень — добуток: `range(3)` і `range(2)` дають 6 кроків.
> Змінні циклів мають бути різними.

> ❓ **Скільки разів виконається тіло у вкладених циклах `range(4)` і `range(5)`?**
>
> *Очікуємо:* двадцять разів.

### Блок 2. Рядки й стовпці

Вкладені цикли природно лягають на все, що має вигляд таблиці. Зовнішній цикл відповідає за рядки, внутрішній — за стовпці.

```
for рядок in range(1, 4):
    for стовпець in range(1, 4):
        print(рядок * стовпець, end=" ")
    print()
```

Виведе:
```
1 2 3
2 4 6
3 6 9
```

Зверніть увагу на два `print`. Внутрішній має `end=" "`, тому числа йдуть в один рядок через пробіл. А порожній `print()` після внутрішнього циклу — але всередині зовнішнього — переводить на новий рядок після кожного рядка таблиці.

Саме цей порожній `print()` найчастіше забувають, і тоді вся таблиця виводиться однією довгою стрічкою.

> 📝 **Таблиця вкладеними циклами:** зовнішній цикл — рядки, внутрішній — стовпці.
> `end=" "` у внутрішньому `print` тримає числа в одному рядку.
> Порожній `print()` після внутрішнього циклу переводить на новий рядок.

> ❓ **Що станеться, якщо прибрати порожній `print()` після внутрішнього циклу?**
>
> *Очікуємо:* усі числа виведуться одним довгим рядком, без поділу на рядки таблиці.

### Блок 3. Фігури з символів

Якщо кількість повторень внутрішнього циклу залежить від змінної зовнішнього, виходять фігури.

```
for i in range(1, 6):
    for j in range(i):
        print("*", end="")
    print()
```

Виведе драбинку:
```
*
**
***
****
*****
```

Секрет у тому, що внутрішній цикл робить `range(i)` кроків — тобто стільки, який зараз номер рядка. У першому рядку одна зірочка, у п'ятому п'ять.

Той самий результат можна отримати й без внутрішнього циклу — множенням тексту з уроку 7: `print("*" * i)`. Обидва способи правильні.

> 📝 **Фігури** виходять, коли межа внутрішнього циклу залежить від змінної зовнішнього: `for j in range(i)`.
> Простий рядок символів можна зробити й множенням: `print("*" * i)`.

> ❓ **Скільки зірочок буде в третьому рядку драбинки?**
>
> *Очікуємо:* три.

**Бонус 4.** Скільки разів виконається тіло внутрішнього циклу, якщо зовнішній має 4 кроки, а внутрішній 5? А якщо всередину вкласти ще третій цикл на 3 кроки?

#### ✅ Відповіді до бонусів

**Бонус 1.**
```
for i in range(1, 6):
    print(" " * (5 - i) + "*" * (2 * i - 1))
```
Ідея: пробілів щоразу на один менше, зірочок — на дві більше, і кількість зірочок у рядку завжди непарна.

**Бонус 2.**
```
for n in range(2, 101):
    просте = True
    for d in range(2, n):
        if n % d == 0:
            просте = False
    if просте:
        print(n, end=" ")
```
Змінна `просте` — це прапорець із уроку 8. Її обнуляють для кожного числа окремо, всередині зовнішнього циклу.

**Бонус 3.** Пар шість: 1-2, 1-3, 1-4, 2-3, 2-4, 3-4. Просте рішення перевіряє всі 16 пар і відкидає зайві через `if`. Розумніше зробити внутрішній цикл **залежним** від зовнішнього:
```
for i in range(1, 5):
    for j in range(i + 1, 5):
        print(i, j)
```
Тоді жодна зайва пара не перевіряється взагалі. Цим прийомом користуються скрізь, де треба перебрати всі пари без повторів.

**Бонус 4.** 4 × 5 = 20 разів, а з третім циклом 4 × 5 × 3 = 60. Кількість перемножується, і це головна причина, чому вкладені цикли швидко стають повільними: три вкладені цикли по сто кроків дадуть мільйон виконань. Тому глибину вкладеності більшу за три в реальних програмах вважають підозрілою.

## 7. Якщо лишився час

**Скільки повторень витримає програма.** Два вкладені цикли по тисячі кроків дають мільйон повторень — це частка секунди. Три вкладені цикли по тисячі дають уже мільярд, і програма рахуватиме кілька хвилин. Чотири — понад добу. Тому в програмуванні окремо стежать за глибиною вкладеності: кожен новий рівень множить час роботи.

**Як влаштована картинка на екрані.** Будь-яке зображення — це таблиця точок, і обробляють його рівно вкладеними циклами: зовнішній іде по рядках, внутрішній по стовпцях. Коли ви накладаєте фільтр на фото, програма проходить кожен піксель саме так. Для звичайного фото це близько дванадцяти мільйонів повторень, і вони встигають виконатися за частки секунди.
