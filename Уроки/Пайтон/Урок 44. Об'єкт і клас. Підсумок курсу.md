### Блок 1. Об'єкти ви вже бачили

Згадайте `оцінки.append(10)`. Чому команда пишеться через крапку, після імені списку? Бо `append` належить саме цьому списку, а не Python узагалі.

Список — це об'єкт. Рядок — теж об'єкт, тому й `слово.upper()`. Вікно з минулого уроку — об'єкт, тому `вікно.title()`.

Об'єкт — це щось, у чого є **власні дані** й **власні команди**. Дані називають атрибутами, команди — методами.

> 📝 **Об'єкт** — щось, у чого є власні дані (**атрибути**) і власні команди (**методи**).
> Метод викликають через крапку: `список.append(5)`, `слово.upper()`.
> Список, рядок і вікно — усе це об'єкти.

> ❓ **Чому `append` пишуть через крапку після імені списку?**
>
> *Очікуємо:* бо це команда самого списку, а не загальна команда мови.

### Блок 2. Клас — це креслення

Об'єктів-списків у програмі може бути багато, і всі вони вміють одне й те саме. Бо всі зроблені за одним описом.

Такий опис називають класом.

**Клас — це креслення. Об'єкт — виріб за цим кресленням.**

Креслення будинку одне, а будинків за ним побудували двадцять, і всі різні: різного кольору, з різними мешканцями. Але вікна й двері в них на однакових місцях, бо креслення спільне.

Так само й тут: клас «Учень» один, а учнів-об'єктів тридцять. Кожен зі своїм прізвищем і своїми оцінками, але всі вміють одне й те саме.

> 📝 **Клас** — опис, за яким створюють об'єкти. **Об'єкт** — конкретний екземпляр, створений за класом.
> Клас — креслення, об'єкт — виріб за ним.

> ❓ **Клас «Книга» описано один раз. Скільки об'єктів-книжок можна за ним створити?**
>
> *Очікуємо:* скільки завгодно.

### Блок 3. Описуємо власний клас

Клас описують командою `class`. Усередині обов'язково є метод із дивною назвою `__init__` — з двома підкресленнями з кожного боку.

```
class Учень:
    def __init__(self, прізвище, клас):
        self.прізвище = прізвище
        self.клас = клас
```

`__init__` виконується **в момент створення об'єкта** й запам'ятовує в ньому передані дані. Його називають конструктором.

`self` — це сам об'єкт. Рядок `self.прізвище = прізвище` означає «запам'ятай у цьому об'єкті прізвище, яке передали». `self` завжди пишуть першим параметром, але при створенні об'єкта його **не передають** — Python підставляє сам.

Тепер створюємо об'єкти:

```
учень1 = Учень("Іваненко", "8-А")
учень2 = Учень("Петренко", "8-Б")

print(учень1.прізвище)     → Іваненко
print(учень2.клас)         → 8-Б
```

Дані кожного учня лежать разом, в одному об'єкті. Жодних трьох списків.

> 📝 **Опис класу:**
>
> ```
> class Учень:
>     def __init__(self, прізвище, клас):
>         self.прізвище = прізвище
>         self.клас = клас
> ```
>
> `__init__` виконується при створенні об'єкта. `self` — сам об'єкт, його пишуть першим параметром, але при створенні не передають.
> **Створення об'єкта:** `учень1 = Учень("Іваненко", "8-А")`
> **Звернення до атрибута:** `учень1.прізвище`

> ❓ **Скільки аргументів передають при створенні `Учень("Іваненко", "8-А")`, якщо в `__init__` три параметри?**
>
> *Очікуємо:* два, бо `self` Python підставляє сам.

### Блок 4. Метод

Метод — це звичайна функція, тільки описана всередині класу. Перший параметр у неї теж `self`.

```
class Учень:
    def __init__(self, прізвище, клас):
        self.прізвище = прізвище
        self.клас = клас
        self.оцінки = []

    def додати_оцінку(self, оцінка):
        self.оцінки.append(оцінка)

    def середній_бал(self):
        if len(self.оцінки) == 0:
            return 0
        return sum(self.оцінки) / len(self.оцінки)

    def представитися(self):
        print(f"{self.прізвище}, {self.клас}, середній бал {self.середній_бал():.1f}")
```

Використання:

```
учень = Учень("Іваненко", "8-А")
учень.додати_оцінку(10)
учень.додати_оцінку(8)
учень.представитися()      → Іваненко, 8-А, середній бал 9.0
```

Зверніть увагу на два моменти. Порожній список оцінок створюється в `__init__` — так у кожного учня буде свій. І метод може викликати інший метод того самого об'єкта, теж через `self`.

> 📝 **Метод** — функція, описана всередині класу. Першим параметром завжди `self`.
> Усередині методу до даних об'єкта звертаються через `self.ім'я`.
> **Виклик:** `об'єкт.метод(аргументи)`.

> ❓ **Навіщо всередині методу писати `self.оцінки`, а не просто `оцінки`?**
>
> *Очікуємо:* щоб звернутися саме до оцінок цього об'єкта, а не до якоїсь окремої змінної.

#### ✅ Відповіді до бонусів

**Бонус 1.** виведеться щось на кшталт `<__main__.Учень object at 0x7f...>` — тип об'єкта й адреса в пам'яті. Щоб виводилось по-людськи, у класі описують спеціальний метод:
```
def __str__(self):
    return f"{self.прізвище} ({self.клас})"
```
Після цього `print(учень1)` виведе `Іваненко (8-А)`. Це той самий механізм, завдяки якому `print` красиво виводить списки й числа.

**Бонус 2.**
```
клас.sort(key=lambda у: у.середній_бал(), reverse=True)
```
Тут `key` каже, за чим саме сортувати — це те розширення сортування, про яке ми згадували на уроці 28. Слово `lambda` означає коротку безіменну функцію: «візьми учня й поверни його середній бал».

**Бонус 3.** Об'єкти створяться всі три, але доступ лишиться тільки до останнього: ім'я `м` щоразу переприсвоюється, а попередні об'єкти губляться. Щоб зберегти всі, їх складають у список:
```
мʼячі = []
for i in range(3):
    мʼячі.append(Мʼяч())
```
Далі до кожного звертаються за індексом або перебирають циклом. Саме так у іграх зберігають ворогів, кулі й частинки.

**Бонус 4.** `self` — це сам об'єкт, до якого застосували метод. Через нього метод дістається власних даних: `self.x`, `self.колір`. Якщо його не написати в дужках, Python усе одно передасть об'єкт першим аргументом, і ви отримаєте помилку `TypeError` про зайвий аргумент. Слово `self` не чарівне, це звичайне ім'я першого параметра, просто так домовилися називати його в усьому світі, і порушувати домовленість не варто.

**Що далі.** Курс закінчився, а Python — ні. Найкраще, що можна зробити далі, — придумати собі задачу, яка вам самим цікава, і розв'язати її. Не вправу з підручника, а щось своє: бот, гру, програму для власних потреб. Усе, чого забракне, знайдеться в інтернеті за десять хвилин — тепер ви вмієте головне: розкладати задачу на кроки.

**Десять проєктів.** Анкета, чек, тест, гра «Вгадай число», щоденник оцінок, генератор варіантів, композиція на turtle, вулиця з хатинок, гра Bounce і калькулятор у вікні. Це десять готових програм, кожну з яких можна показати.

**Захист робіт.** Три хвилини на автора. Розкажіть: що робить ваша програма · які прийоми з курсу ви в ній використали · що було найважче · що б ви доробили, якби мали ще тиждень.

## 7. Домашнє завдання

Домашнього завдання після останнього уроку немає.

Замість нього — пропозиція. Візьміть будь-який зі своїх проєктів курсу і зробіть із нього щось, чим справді користуватиметеся. Тест перетворіть на тренажер із того предмета, який погано йде. Щоденник — на облік своїх витрат. Генератор варіантів — на розподіл домашніх обов'язків. А гру Bounce доведіть до стану, у який захочуть грати друзі.

Програма, якою ви користуєтесь самі, навчить більше, ніж десять навчальних вправ.

## 8. Якщо лишився час

**Скільки років ідеї об'єктів.** Перша мова з класами й об'єктами — Simula — з'явилася в 1967 році в Норвегії, і придумали її для моделювання роботи портів і черг. Ідея була проста: якщо в задачі є кораблі й причали, то нехай і в програмі будуть кораблі й причали. Через тридцять років на цьому підході було написано більшість програм у світі.

**Чому `self` пишуть явно.** У багатьох мовах усередині методу до даних об'єкта звертаються просто за іменем, без жодного префікса. Python вимагає писати `self` завжди, і це свідоме рішення: дивлячись на рядок, одразу видно, чи це дані об'єкта, чи звичайна змінна. Автор мови вважав явність важливішою за стислість — і те саме правило пояснює, чому в Python обов'язкові відступи.
