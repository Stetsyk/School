## 2. Пояснення (12-15 хв)

### Блок 1. Команда while

`while` англійською означає «поки». Записується так:

```
товщина = 0.1
кроків = 0
while товщина < 1000:
    товщина *= 2
    кроків += 1
print("Згинів:", кроків)
```

Читається просто: поки товщина менша за 1000 міліметрів — подвоювати й рахувати.

Будова майже така сама, як в `if`: умова, двокрапка, тіло з відступом. Різниця в тому, що `if` перевіряє умову один раз, а `while` — перед кожним повторенням.

> 📝 **Цикл з передумовою:**
>
> ```
> while умова:
>     дія
> ```
>
> Повторює тіло, **поки умова істинна**. Умова перевіряється **перед** кожним повторенням.

> ❓ **Чим `while` відрізняється від `if` за записом і за роботою?**
>
> *Очікуємо:* записом майже нічим, а працює інакше: `if` перевіряє один раз, `while` — перед кожним повторенням.

### Блок 2. Найважливіше правило

У тілі `while` обов'язково має бути щось, що **змінює умову**. Інакше вона ніколи не стане хибною, і цикл працюватиме вічно.

```
n = 10
while n > 0:
    print(n)
```

Ця програма виводитиме десятку нескінченно. Умова `n > 0` істинна завжди, бо `n` ніхто не змінює.

Виправлення — додати рядок, який рухає нас до виходу:

```
n = 10
while n > 0:
    print(n)
    n -= 1
```

Тепер `n` щокроку зменшується, і на нулі цикл зупиниться.

> 📝 **У тілі `while` обов'язково має бути дія, яка змінює умову.** Інакше цикл стане нескінченним.
> Зупинити нескінченний цикл можна комбінацією клавіш **Ctrl + C**.

> ❓ **Чому цикл `while n > 0: print(n)` ніколи не зупиниться?**
>
> *Очікуємо:* усередині нічого не змінює `n`, тому умова лишається істинною завжди.

### Блок 3. Коли брати for, а коли while

Правило просте.

**`for`** — коли кількість повторень **відома наперед**: десять питань тесту, числа від 1 до 100, сім днів тижня.

**`while`** — коли кількість повторень **залежить від результату**: поки не введуть правильний пароль, поки сума не перевищить тисячу, поки число більше за одиницю.

| Ситуація | Який цикл |
| --- | :---: |
| Вивести числа від 1 до 50 | `for` |
| Питати пароль, поки не введуть правильний | `while` |
| Порахувати суму десяти оцінок | `for` |
| Ділити число навпіл, поки воно більше за 1 | `while` |

> 📝 **`for`** — коли кількість повторень відома наперед.
> **`while`** — коли повторюємо, поки виконується умова, і кількість кроків заздалегідь невідома.

> ❓ **Який цикл узяти, щоб питати число, поки користувач не введе нуль?**
>
> *Очікуємо:* `while`, бо невідомо, коли він це зробить.

### Блок 4. Команда break

Іноді вийти з циклу треба посеред роботи, не чекаючи перевірки умови. Для цього є `break` — вона негайно припиняє цикл.

```
while True:
    відповідь = input("Введіть число або 'вихід': ")
    if відповідь == "вихід":
        break
    print("Ви ввели", відповідь)
print("Програму завершено")
```

Запис `while True` означає «повторюй завжди» — умова істинна за визначенням. Такий цикл був би нескінченним, якби не `break` усередині.

Цей прийом використовують для меню й для повторного введення: цикл крутиться, поки користувач сам не вирішить вийти.

> 📝 **`break`** негайно припиняє цикл і передає керування рядку після нього.
> `while True:` разом із `break` усередині — стандартний прийом для меню й повторного введення.

> ❓ **Що станеться з циклом `while True`, якщо в ньому немає `break`?**
>
> *Очікуємо:* він працюватиме нескінченно.


### Блок 5. Алгоритм гри

Опишемо гру словами, перш ніж писати код.

1. Загадати число
2. Обнулити лічильник спроб
3. Повторювати: запитати варіант → збільшити лічильник → якщо вгадав, вийти → інакше підказати «більше» чи «менше»
4. Вивести результат і кількість спроб

Найважливіше питання: який цикл узяти? Кількість спроб наперед невідома, вона залежить від гравця. Отже, `while`.

> 📝 **Алгоритм гри:** загадати → обнулити лічильник → повторювати запит із підказками, поки не вгадано → вивести кількість спроб.
> Кількість спроб невідома наперед, тому потрібен цикл `while`.

> ❓ **Чому для цієї гри не підходить цикл `for`?**
>
> *Очікуємо:* невідомо наперед, скільки спроб знадобиться гравцеві.

### Блок 6. Основа програми

```
загадане = 42
спроб = 0

while True:
    варіант = int(input("Ваш варіант: "))
    спроб += 1
    if варіант == загадане:
        print(f"Вгадали за {спроб} спроб!")
        break
    elif варіант < загадане:
        print("Більше")
    else:
        print("Менше")
```

Тут працює прийом із блоку 4: `while True` крутить цикл нескінченно, а `break` виходить із нього, коли гравець вгадав.

Зверніть увагу на порядок гілок: спершу перевіряємо збіг, і лише потім — у який бік помилка. Якби першою стояла перевірка «менше», гілка з перемогою просто ніколи б не спрацювала.

> 📝 **Основа гри:** `while True` крутить цикл, `break` виходить при вгадуванні.
> Спершу перевіряють збіг, потім напрямок помилки.

> ❓ **Що станеться, якщо в цій програмі прибрати `break`?**
>
> *Очікуємо:* гра не закінчиться навіть після правильної відповіді, цикл крутитиметься далі.

### Блок 7. Обмеження спроб

Щоб гра стала складнішою, обмежимо кількість спроб. Тоді умова циклу перестає бути `True` і стає осмисленою:

```
while спроб < 7:
    ...
```

Але тут з'являється тонкість: після виходу з циклу треба зрозуміти, чому саме він закінчився — гравець вгадав чи спроби скінчилися. Для цього заводять прапорець:

```
вгадав = False
while спроб < 7 and not вгадав:
    ...
    if варіант == загадане:
        вгадав = True
```

Після циклу перевіряємо прапорець і виводимо потрібне повідомлення.

> 📝 **Прапорець** — змінна `True` або `False`, яка запам'ятовує, чи сталася подія. Після циклу її перевіряють, щоб зрозуміти, чим цикл закінчився.

> ❓ **Навіщо потрібен прапорець, якщо є `break`?**
>
> *Очікуємо:* щоб після виходу з циклу знати, чи гравець вгадав, чи просто вичерпав спроби.

## 5. ⭐ Бонус для сильних

**Бонус 1. Розстрочка.** Телефон коштує 9000 грн, і його беруть у розстрочку: щомісяця платять 1200 грн, а останнім платежем — те, що лишилося. Напишіть програму, яка виводить кожен платіж (`Місяць 3: 1200 грн, лишилось 5400 грн`) і наприкінці — скільки місяців знадобилося.

**Бонус 2. Батарея.** Телефон заряджений на 100%, а кожні 10 хвилин гри забирають 7% заряду. Через скільки хвилин заряд уперше опуститься до 15% або нижче й телефон покаже попередження? Скільки відсотків лишиться в цей момент?

**Бонус 3. ПІН-код.** Банкомат дає три спроби ввести ПІН-код. Напишіть програму, яка запитує код, поки його не введуть правильно, але не більше трьох разів. Після правильного коду — `Вхід виконано`, після трьох помилок — `Картку заблоковано`. Правильний код задайте в програмі.

**Бонус 4.** Ви запустили програму, і вона нічого не виводить і не зупиняється. Що сталося, як зупинити її та які три причини найімовірніші?

**Бонус 5.** Скільки спроб потрібно для діапазону від 1 до 1000? А від 1 до мільйона?

**Бонус 6.** Комп'ютер загадав число від 1 до 100. Яка стратегія гарантує перемогу найшвидше і за скільки спроб у найгіршому випадку?

**Бонус 7.** Поміняйтеся ролями: тепер **комп'ютер** відгадує задумане вами число, а ви відповідаєте «більше», «менше» або «вгадав». Опишіть алгоритм програми.

#### ✅ Відповіді до бонусів

**Бонус 1.** 8 місяців: сім платежів по 1200 і останній — 600 грн.
```
борг = 9000
місяць = 0
while борг > 0:
    місяць += 1
    if борг >= 1200:
        платіж = 1200
    else:
        платіж = борг
    борг -= платіж
    print(f"Місяць {місяць}: {платіж} грн, лишилось {борг} грн")
print("Розстрочку закрито за", місяць, "місяців")
```
Головна ідея: умова `борг > 0`, а не `борг >= 1200`, інакше останній неповний платіж загубиться. Скільки місяців — наперед невідомо, тому тут `while`, а не `for`.

**Бонус 2.** Через 130 хвилин, лишиться 9%.
```
заряд = 100
хвилин = 0
while заряд > 15:
    заряд -= 7
    хвилин += 10
print(хвилин, "хв, заряд", заряд, "%")
```
Пастка в умові: на 120-й хвилині заряд 16%, це ще більше за 15, тому цикл робить ще один крок. Хто напише `while заряд >= 15`, отримає ту саму відповідь тільки випадково — варто перевірити на іншому кроці розряду, наприклад 5%.

**Бонус 3.**
```
код = "4821"
спроб = 0
while спроб < 3:
    введено = input("ПІН-код: ")
    спроб += 1
    if введено == код:
        print("Вхід виконано")
        break
    print("Невірний код")
if введено != код:
    print("Картку заблоковано")
```
Тут дві причини вийти з циклу: правильний код (`break`) або вичерпані спроби (умова `while`). Після циклу треба перевірити, яка саме спрацювала. ПІН-код зберігають текстом, бо `"0123"` як число втратив би нуль на початку.

**Бонус 4.** Це нескінченний цикл. Зупиняють поєднанням `Ctrl + C` у вікні виконання. Три звичні причини: змінна умови взагалі не змінюється в тілі циклу · вона змінюється, але в інший бік і ніколи не дійде до межі · рядок зі зміною випадково опинився поза відступом і виконується вже після циклу. Перевірка одна: знайти в тілі рядок, який наближає умову до хибності, і переконатися, що він там справді є.

**Бонус 5.** 10 і 20. Кожна спроба ділить діапазон навпіл, тому кількість спроб — це степінь двійки, найближчий згори: 2 у десятому степені це 1024, 2 у двадцятому — понад мільйон. Тобто діапазон збільшився в тисячу разів, а спроб знадобилося лише вдвічі більше.

**Бонус 6.** Називати щоразу **середину** проміжку, що лишився: спершу 50, потім 25 або 75 і так далі. Кожна спроба зменшує кількість варіантів удвічі: 100 → 50 → 25 → 13 → 7 → 4 → 2 → 1, тобто **сім** спроб у найгіршому випадку. Спосіб називають двійковим пошуком, і саме ним ваш телефон знаходить контакт серед тисяч записів.

**Бонус 7.** Програма тримає дві межі й називає середину.
```
низ = 1
верх = 100
while True:
    спроба = (низ + верх) // 2
    print("Це", спроба, "?")
    відповідь = input("більше / менше / вгадав: ")
    if відповідь == "вгадав":
        break
    elif відповідь == "більше":
        низ = спроба + 1
    else:
        верх = спроба - 1
```
Головна деталь — `+ 1` і `− 1` при зсуві меж: без них програма може назвати те саме число вдруге й зациклитися.

## 7. Якщо лишився час

**Чому аркуш неможливо скласти більше семи разів.** Задача про товщину має продовження: фізично складати аркуш більше семи разів дуже важко, бо на кожному згині подвоюється не лише товщина, а й опір паперу. Рекорд поставила американська школярка Брітні Ґаллівен у 2002 році — вона склала спеціально виготовлений рулон туалетного паперу довжиною 1200 метрів дванадцять разів. Для цього довелося вивести формулу, яка пов'язує довжину аркуша з можливою кількістю згинів.

**Найвідоміше зациклення в іграх.** Помилка, коли гра назавжди застигає в одному стані, називається softlock. Класичний випадок: персонаж потрапляє в місце, звідки неможливо вийти, а гра при цьому працює нормально. Формально це те саме нескінченне очікування умови, яка ніколи не настане.

**Як називається ваша стратегія.** Поділ діапазону навпіл — це двійковий пошук, один із найважливіших алгоритмів в інформатиці. Ним користуються скрізь, де треба щось швидко знайти у впорядкованих даних. Саме тому телефонний довідник, словник і зміст книжки влаштовані за абеткою: у впорядкованому наборі знайти потрібне можна за лічені кроки.

**Двадцять питань.** Є стара гра, де один загадує будь-який предмет у світі, а інший має вгадати за двадцять питань із відповідями «так» або «ні». Двадцять питань дають понад мільйон варіантів, і цього достатньо для більшості предметів. Та сама математика, що в бонусі 2.
