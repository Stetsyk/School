## 2. Пояснення (7-9 хв)

### Блок 1. split: із тексту в список

Метод `split` розрізає рядок на частини по пробілах і повертає список.

```
речення = "Я вивчаю Python"
слова = речення.split()
print(слова)          → ['Я', 'вивчаю', 'Python']
print(len(слова))     → 3
```

Тепер це справжній список, з яким працює все, що ми вивчили: індекси, перебір, `len`, сортування.

Порахувати кількість слів у реченні тепер можна одним рядком: `len(речення.split())`.

Якщо частини розділені не пробілом, розділювач указують у дужках:

```
дата = "12.05.2026"
print(дата.split("."))     → ['12', '05', '2026']
```

> 📝 **`split()`** розрізає рядок на список частин.
> Без аргументу ріже по пробілах: `"я вивчаю".split()` дає `['я', 'вивчаю']`
> З аргументом — по вказаному символу: `"12.05.2026".split(".")`

> ❓ **Скільки елементів дасть `"один два три".split()`?**
>
> *Очікуємо:* три.

### Блок 2. Числа з рядка

Головна пастка та сама, що з `input`: після `split` частини лишаються **текстом**, навіть якщо це цифри.

```
рядок = "5 7 9"
частини = рядок.split()
print(частини)              → ['5', '7', '9']    це тексти
```

Щоб рахувати, кожну частину треба перетворити. Робиться це циклом із відбором у новий список — прийомом з уроку 27:

```
числа = []
for частина in рядок.split():
    числа.append(int(частина))
print(sum(числа))          → 21
```

> 📝 **Після `split` частини лишаються текстом.** Щоб рахувати, їх перетворюють у циклі:
>
> ```
> числа = []
> for ч in рядок.split():
>     числа.append(int(ч))
> ```

> ❓ **Чому `sum("5 7 9".split())` не спрацює?**
>
> *Очікуємо:* у списку лежать тексти, а не числа, додавати їх не можна.

### Блок 3. join: зі списку в текст

Зворотна дія. Метод `join` збирає список у один рядок, вставляючи між елементами вказаний розділювач.

Запис незвичний: розділювач іде **першим**, а список у дужках.

```
слова = ["Київ", "Львів", "Одеса"]
print(", ".join(слова))     → Київ, Львів, Одеса
print(" - ".join(слова))    → Київ - Львів - Одеса
```

Це найзручніший спосіб красиво вивести список: без `join` вивелися б квадратні дужки й лапки.

Важливе обмеження: `join` працює лише зі списком **текстів**. Якщо там числа, спершу їх треба перетворити в текст.

Разом ці дві команди дають типову зв'язку: **розбити → опрацювати → зібрати**.

> 📝 **`join`** збирає список у рядок: `", ".join(список)`
> Розділювач пишеться **перед** крапкою, список — у дужках.
> Працює лише зі списком **текстів**.

> ❓ **Що виведе `"-".join(["а", "б", "в"])`?**
>
> *Очікуємо:* `а-б-в`.

#### ✅ Відповіді до бонусів

**Бонус 1.**
```
речення = input("Речення: ")
слова = речення.split()
print(" ".join(слова[::-1]))
```
Тут працює вся зв'язка: розбити, перевернути зрізом, зібрати назад.

**Бонус 2.**
```
рядок = input("Дані: ")
частини = рядок.split(";")
ім'я = частини[0]
оцінки = []
for ч in частини[1:]:
    оцінки.append(int(ч))
print(f"{ім'я}: середній бал {sum(оцінки) / len(оцінки):.1f}")
```
Головна ідея: зріз `частини[1:]` бере все, крім першого елемента. Саме так читають дані з таблиць, збережених текстом.

**Бонус 3.**
```
дата = "12.05.2026"
день, місяць, рік = дата.split(".")
місяці = ["січня","лютого","березня","квітня","травня","червня",
          "липня","серпня","вересня","жовтня","листопада","грудня"]
print(день, місяці[int(місяць) - 1], рік, "року")
```
Головна деталь — `int(місяць) - 1`: у списку нумерація з нуля, а місяці людина рахує з одиниці.

**Бонус 4.** Буде помилка `TypeError`: `join` уміє склеювати тільки **тексти**, а в списку числа. Виправляють перетворенням кожного елемента:
```
числа = [1, 2, 3]
тексти = []
for n in числа:
    тексти.append(str(n))
print("-".join(тексти))
```
Виведе `1-2-3`. Це дзеркальна ситуація до `split`: там текст перетворювали на числа, тут числа доводиться перетворювати на текст.

## 7. Якщо лишився час

**Найпоширеніший формат даних у світі.** Таблиці часто зберігають у форматі CSV — це звичайний текстовий файл, у якому значення розділені комами, а кожен рядок є рядком таблиці. Прочитати такий файл можна саме `split(",")` для кожного рядка. У цьому форматі експортують дані майже всі програми — від бухгалтерських до наукових, бо він простий і читається будь-де.

**Чому в join розділювач стоїть попереду.** Запис `", ".join(список)` спершу здається перевернутим. Але логіка є: `join` — метод **рядка-розділювача**, а не списку. Ми ніби кажемо цьому рядку: «встань між елементами цього списку». Незвично, зате той самий розділювач можна легко застосувати до різних списків.
