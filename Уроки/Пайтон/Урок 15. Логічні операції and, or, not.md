## 1. Вступ-гачок (2-3 хв)

Мама каже: «Підеш гуляти, **якщо** зробиш уроки **і** прибереш у кімнаті».

Скільки умов? Дві. Скільки треба виконати? Обидві. Зробив уроки, але не прибрав — гуляти не йдеш.

А тепер інше: «Можеш не йти до школи, **якщо** захворів **або** сьогодні вихідний». Тут теж дві умови, але достатньо однієї.

Різниця в одному слові — «і» чи «або». І від нього залежить усе.

Наші програми поки що вміють перевіряти тільки одну річ за раз. Сьогодні навчимо їх перевіряти кілька умов одночасно — і це саме те, чого потребує будь-яка реальна програма.

## 2. Пояснення (8-10 хв)

### Блок 1. Операція and

`and` англійською — «і». З'єднує дві умови, і результат істинний, **тільки коли обидві істинні**.

```
уроки_зроблені = True
кімната_прибрана = False
if уроки_зроблені and кімната_прибрана:
    print("Можна гуляти")
else:
    print("Спочатку зроби все")
```

Тут виведеться друге, бо одна з умов хибна.

Умови можна писати не тільки змінними, а й прямо порівняннями:

```
if вік >= 14 and зріст >= 140:
    print("Можна на атракціон")
```

> 📝 **Операція `and` (і)** — істинна, тільки коли **обидві** умови істинні.
>
> | Умова 1 | Умова 2 | Результат |
> | :---: | :---: | :---: |
> | True | True | True |
> | True | False | False |
> | False | True | False |
> | False | False | False |

> ❓ **Чи пустять на атракціон людину віком 15 років і зростом 130 см за умовою `вік >= 14 and зріст >= 140`?**
>
> *Очікуємо:* ні, бо друга умова хибна, а при `and` потрібні обидві.

### Блок 2. Операція or

`or` англійською — «або». Результат істинний, коли істинна **хоча б одна** умова.

```
if день == "субота" or день == "неділя":
    print("Вихідний!")
```

Тут вистачить збігу з одним із двох варіантів.

Важливо: у програмуванні «або» не виключне. Якщо істинні обидві умови, результат теж істинний. Це відрізняється від побутового «або», де зазвичай мають на увазі «одне з двох».

> 📝 **Операція `or` (або)** — істинна, коли істинна **хоча б одна** умова.
>
> | Умова 1 | Умова 2 | Результат |
> | :---: | :---: | :---: |
> | True | True | True |
> | True | False | True |
> | False | True | True |
> | False | False | False |

> ❓ **Що дасть умова `5 > 3 or 2 > 10`?**
>
> *Очікуємо:* True, бо перша частина істинна, і цього достатньо.

### Блок 3. Операція not

`not` англійською — «не». Ставиться перед умовою й перевертає її: істинне робить хибним і навпаки.

```
if not двері_зачинені:
    print("Зачини двері!")
```

Найчастіше `not` використовують зі змінними-прапорцями, бо так речення читається природно: «якщо не зачинені».

> 📝 **Операція `not` (не)** перевертає значення умови: `not True` дає False, `not False` дає True.

> ❓ **Що дасть `not (5 > 3)`?**
>
> *Очікуємо:* False, бо всередині істина, а `not` її перевертає.

### Блок 4. Діапазон і головна помилка

Дуже часта задача: перевірити, чи потрапляє число в проміжок. Наприклад, чи оцінка від 7 до 9 включно.

Природно хочеться написати `if оцінка > 7 or < 9`. Так не можна — Python не зрозуміє. **Кожна умова має бути повною**, з обома частинами.

```
if оцінка >= 7 and оцінка <= 9:
    print("Достатній рівень")
```

У Python є ще й короткий запис, який працює точно як у математиці:

```
if 7 <= оцінка <= 9:
    print("Достатній рівень")
```

Обидва варіанти правильні, другий читається краще.

> 📝 **Перевірка діапазону:**
> `if 7 <= оцінка <= 9:` — короткий запис
> `if оцінка >= 7 and оцінка <= 9:` — повний запис
> **Неправильно:** `if оцінка >= 7 and <= 9` — у кожної умови має бути своя змінна.

> ❓ **Чому запис `if n > 10 and < 20` неправильний?**
>
> *Очікуємо:* у другій умові немає змінної, треба `and n < 20`.

## 3. Перевірка розуміння (3-5 хв)

1. **Коли істинна умова з `and`?**
   Коли істинні обидві частини.

2. **Коли істинна умова з `or`?**
   Коли істинна хоча б одна частина.

3. **Що робить `not`?**
   Перевертає значення умови на протилежне.

4. **Як перевірити, чи число від 1 до 100?**
   `if 1 <= n <= 100:` або `if n >= 1 and n <= 100:`

5. **Чому не можна писати `if n > 5 and < 10`?**
   Друга умова неповна, у ній немає змінної.

## 5. ⭐ Бонус для сильних

**Бонус 1.** Що виведе програма й чому саме так?
```
if 5 > 3 or 10 / 0 > 1:
    print("Працює")
```

**Бонус 2.** Запишіть одним рядком умову «рік високосний». Правило: рік високосний, якщо ділиться на 4, але не ділиться на 100, або якщо ділиться на 400.

**Бонус 3.** Учень записав умову «число в межах від 10 до 20 включно» як `if n >= 10 and <= 20:` і отримав помилку. Виправте її **двома** способами.

**Бонус 4.** Перевірте на прикладі, що `not (A and B)` дає той самий результат, що й `not A or not B`. Візьміть `A` це `5 > 3`, `B` це `2 > 4`.

#### ✅ Відповіді до бонусів

**Бонус 1.** виведе `Працює` без помилки. Python перевіряє умови зліва направо й зупиняється, щойно відповідь стає зрозумілою. Оскільки перша частина істинна, а операція `or`, друга частина взагалі не обчислюється, і ділення на нуль не відбувається. Це називається лінивим обчисленням.

**Бонус 2.**
```
if (рік % 4 == 0 and рік % 100 != 0) or рік % 400 == 0:
```
Дужки тут обов'язкові, без них порядок обчислення зміниться й 1900 рік буде помилково визнаний високосним.

**Бонус 3.** Помилка в тому, що після `and` має стояти **повноцінна умова**, а не її хвіст: Python не здогадується, що йдеться про те саме `n`. Перший спосіб: `if n >= 10 and n <= 20:`. Другий, коротший і саме в дусі Python: `if 10 <= n <= 20:`. Обидва працюють однаково, другий читається як математичний запис.

**Бонус 4.** `A` істинне, `B` хибне. Перший запис: `5 > 3 and 2 > 4` хибне, отже `not` від нього дає `True`. Другий: `not A` хибне, `not B` істинне, `хибне or істинне` дає `True`. Результати збігаються. Це правило називають законом де Моргана, і воно працює завжди: заперечення «і» перетворюється на «або» заперечень, і навпаки. Практична користь у тому, що складну умову часто легше сформулювати через заперечення, а потім переписати зрозуміліше.

## 7. Якщо лишився час

**Звідки взялися ці операції.** Це та сама булева алгебра, про яку ми згадували на уроці 8. Джордж Буль описав `and`, `or` і `not` у 1854 році як чисту математику. Через вісімдесят років студент Клод Шеннон помітив, що електричні перемикачі поводяться точно за цими правилами: два вимикачі послідовно — це `and`, паралельно — `or`. Його дипломна робота вважається однією з найважливіших в історії техніки.

**Чому `and` і `or` пишуть словами.** У більшості мов програмування ці операції позначають значками: подвійний амперсанд і дві вертикальні риски. Python свідомо взяв англійські слова, бо код тоді читається як речення. Значки в Python теж є, але означають зовсім інше — побітові операції, які працюють з окремими бітами числа.
