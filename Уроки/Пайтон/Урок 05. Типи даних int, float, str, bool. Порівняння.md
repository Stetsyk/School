## 1. Вступ-гачок (2-3 хв)

Питання: скільки буде `2 + 2`?

Чотири, звісно. А скільки буде `"2" + "2"` — те саме, але в лапках?

Python відповість `22`. Не двадцять два, а два і два поспіль.

Це не помилка й не жарт. Просто в лапках лежить **не число, а текст**, а текст не додають — його склеюють. Так само як `"кіт" + "еня"` дасть `котеня`.

Оце і є типи даних. Одні й ті самі символи, залежно від типу, поводяться зовсім по-різному.

А тепер два твердження. «Київ — столиця України» — правда. «У тижні вісім днів» — неправда. Третього не дано. Для таких відповідей у Python є ще один тип, у якому всього два значення. Виглядає бідно, а насправді на ньому тримаються всі рішення програми: чи правильний пароль, чи закінчилися патрони, чи вистачає грошей на рахунку.

Сьогодні розберемось, які типи бувають, як дізнатися тип і як перевести одне в інше, а наприкінці навчимо Python відповідати «правда» чи «неправда». Без першого не працюватиме введення даних на наступному уроці, без другого — розгалуження на уроці 8.

## 2. Пояснення (12-15 хв)

### Блок 1. Три типи, які треба знати

**int** — цілі числа: `5`, `0`, `-12`, `1000`. Назва від англійського *integer*, ціле.

**float** — числа з дробовою частиною: `2.5`, `-3.14`, `0.75`. Дробова частина завжди через **крапку**.

**str** — текст, його ще називають рядком. Береться в лапки: `"привіт"`, `"Іван"`, `"2 + 2"`. Назва від *string*, рядок.

У Python тип не треба оголошувати заздалегідь — він визначається сам, за тим значенням, яке ви поклали в змінну. Написали `n = 7` — це int. Написали `n = 7.0` — уже float. Написали `n = "7"` — це вже текст.

Дізнатися тип можна командою `type()`:

```
print(type(5))        → <class 'int'>
print(type(2.5))      → <class 'float'>
print(type("5"))      → <class 'str'>
```

> 📝 **Три основні типи даних:**
>
> | Тип | Що це | Приклади |
> | :---: | --- | --- |
> | `int` | цілі числа | `5`, `0`, `-12` |
> | `float` | числа з дробовою частиною | `2.5`, `-3.14` |
> | `str` | текст у лапках | `"привіт"`, `"7"` |
>
> Тип визначається автоматично за значенням. Команда `type()` його показує.

> ❓ **Якого типу значення `18`, `18.0` і `"18"`?**
>
> *Очікуємо:* int, float і str відповідно. Виглядають схоже, а типи різні.

### Блок 2. Що вміє текст

З рядками працюють двома діями, і обидві виглядають несподівано.

**Склеювання** через `+`. Два тексти з'єднуються в один, пробіл сам не додається.

```
імя = "Іван"
прізвище = "Коваль"
print(імя + прізвище)        → ІванКоваль
print(імя + " " + прізвище)  → Іван Коваль
```

**Повторення** через `*`. Текст помножений на число повторюється стільки разів.

```
print("-" * 20)        → --------------------
print("ха" * 3)        → хахаха
```

Ще корисна команда `len()` — показує, скільки символів у тексті, разом із пробілами.

> 📝 **Дії з текстом:**
> `+` склеює два тексти: `"кіт" + "еня"` дає `котеня`
> `*` повторює текст: `"=" * 10` дає рядок із десяти знаків рівності
> `len()` рахує кількість символів

> ❓ **Що виведе `print("ок" * 4)`?**
>
> *Очікуємо:* `окококок`.

### Блок 3. Що НЕ можна робити з типами

Головна заборона: **число й текст не можна складати разом**.

```
вік = 13
print("Мені " + вік + " років")     → помилка TypeError
```

Python не знає, що робити: чи додати число, чи склеїти текст. І чесно про це каже — `TypeError`, помилка типу.

Так само не можна порівнювати текст із числом і не можна множити текст на текст.

> 📝 **TypeError** — помилка типу. Виникає, коли з даними намагаються зробити те, чого їхній тип не дозволяє. Найчастіший випадок — склеїти текст із числом.

> ❓ **Чому рядок `print("Оцінка: " + 10)` не спрацює?**
>
> *Очікуємо:* зліва текст, справа число, склеїти їх напряму не можна.

### Блок 4. Перетворення типів

Вихід простий: перевести одне в інше. Для цього є три команди.

```
str(13)        → "13"     число стає текстом
int("13")      → 13       текст стає цілим числом
float("2.5")   → 2.5      текст стає дробовим числом
int(7.9)       → 7        дробове стає цілим, хвіст відкидається
```

Тепер попередній приклад працює:

```
вік = 13
print("Мені " + str(вік) + " років")     → Мені 13 років
```

Два важливі моменти. `int()` не округлює, а **відкидає** дробову частину: з 7.9 вийде 7, а не 8. І перетворити в число можна тільки те, що справді схоже на число: `int("привіт")` дасть помилку `ValueError`.

> 📝 **Перетворення типів:**
> `str(число)` — зробити з числа текст
> `int(текст)` — зробити ціле число
> `float(текст)` — зробити дробове число
> `int()` відкидає дробову частину, а не округлює: `int(7.9)` дає 7.

> ❓ **Що дасть `int(9.99)` і чому не 10?**
>
> *Очікуємо:* 9. Дробова частина просто відкидається, округлення тут немає.


### Блок 5. Тип bool: два значення

Крім чисел і тексту, у Python є тип із рівно двома значеннями: `True` (істина) і `False` (хиба). Називається він `bool`.

Пишуться обидва **англійською і з великої літери**. `true` з малої Python не зрозуміє.

```
світло_увімкнене = True
йде_дощ = False
print(type(True))     → <class 'bool'>
```

> 📝 **Тип `bool`** має лише два значення: `True` — істина, `False` — хиба.
> Пишуться англійською з великої літери.

> ❓ **Яке значення матиме твердження «сьогодні понеділок», якщо сьогодні середа?**
>
> *Очікуємо:* False.

### Блок 6. Порівняння

Звідки беруться значення `True` і `False`? Найчастіше — з порівнянь. Порівняння це вираз, результатом якого є істина або хиба.

```
print(5 > 3)        → True
print(10 < 2)       → False
print(7 == 7)       → True
print(4 != 4)       → False
```

Знаків порівняння шість:

| Знак | Значення |
| :---: | --- |
| `>` | більше |
| `<` | менше |
| `>=` | більше або дорівнює |
| `<=` | менше або дорівнює |
| `==` | дорівнює |
| `!=` | не дорівнює |

> 📝 **Знаки порівняння:** `>` `<` `>=` `<=` `==` `!=`
> Результатом порівняння завжди є `True` або `False`.

> ❓ **Що виведе `print(8 >= 8)`?**
>
> *Очікуємо:* True, бо знак означає «більше **або** дорівнює».

### Блок 7. Один знак рівності і два

Ось найважливіше на уроці й найчастіша помилка всього курсу.

**`=` — це присвоєння.** Команда: поклади значення у змінну.
**`==` — це порівняння.** Питання: а чи однакові ці двоє?

```
вік = 13          # присвоїли: у змінній тепер 13
print(вік == 13)  # запитали: чи дорівнює 13? → True
```

Запам'ятати легко: одна риска — одна дія, дві риски — питання. Якщо в програмі має бути питання, а ви поставите одну риску, Python або видасть помилку, або мовчки зіпсує змінну.

> 📝 **`=` кладе значення у змінну.** `x = 5` означає «поклади 5 у x».
> **`==` порівнює два значення.** `x == 5` означає «чи дорівнює x п'ятірці».

> ❓ **Чим відрізняються рядки `оцінка = 10` і `оцінка == 10`?**
>
> *Очікуємо:* перший кладе десятку в змінну, другий питає, чи там уже десятка, і дає True або False.

### Блок 8. Результат порівняння можна зберегти

Порівняння — звичайний вираз, тому його результат можна покласти у змінну, як і будь-яке число.

```
бал = 9
склав = бал >= 6
print(склав)          → True
```

У змінній `склав` тепер лежить `True`. Такі змінні називають прапорцями: вони запам'ятовують, чи виконалась якась умова, щоб перевірити її пізніше.

Порівнювати можна не тільки числа, а й текст. Два тексти рівні, якщо збігаються повністю, символ у символ. Великі й малі літери при цьому вважаються різними.

```
print("кіт" == "кіт")     → True
print("Кіт" == "кіт")     → False
```

> 📝 Результат порівняння можна зберегти у змінній: `склав = бал >= 6`
> Текст порівнюється посимвольно. `"Кіт"` і `"кіт"` — різні рядки.

> ❓ **Чому `"Так" == "так"` дає False?**
>
> *Очікуємо:* велика і мала літера — різні символи, тому рядки не збігаються.

**Бонус 2.** `print(str(n) * n)`. Спершу число перетворюємо в текст, потім повторюємо його `n` разів.

**Бонус 3.** `73` — склеювання двох текстів · `10` — додавання двох чисел · `777` — повторення тексту тричі · `21` — звичайне множення. Ті самі знаки роблять зовсім різні речі залежно від типу того, що поруч. Саме тому тип важливіший за вигляд.

**Бонус 4.** `int` перетворює текст, який виглядає як **ціле** число, і крапка в такий запис не входить. `float("7.5")` спершу робить із тексту дробове число 7.5, і вже його `int` перетворює на ціле. Зверніть увагу: `int` не округлює, а **відкидає** дробову частину, тому з 7.9 теж вийде 7, а не 8.

**Бонус 5.** `2` і `5`. Усередині Python `True` це одиниця, а `False` — нуль. Саме тому кількість виконаних умов можна рахувати простим додаванням: `(вік > 12) + (зріст > 150) + (є_довідка)` одразу дає, скільки вимог справдилося, без жодного `if`.

**Бонус 6.** True. Текст порівнюється за абеткою, буква за буквою, як у словнику. Літера «я» йде після «б», але порівняння дивиться на перші літери за кодами символів, тому результат залежить від кодування. Головна ідея, яку треба зафіксувати: рядки порівнюються посимвольно, а не за довжиною.

**Бонус 7.** `True`, `True` і `True`. Python дозволяє записувати порівняння ланцюжком: він перевіряє кожну пару окремо й з'єднує результати як «і». Третій вираз істинний, бо істинні обидві його частини: 3 < 5 і 5 > 4. У більшості інших мов програмування так писати не можна взагалі.

## 7. Якщо лишився час

**Чому 0.1 + 0.2 не дорівнює 0.3.** Спробуйте порахувати це в Python — вийде `0.30000000000000004`. Причина в тому, що комп'ютер зберігає дроби у двійковій системі, а дріб 0.1 у ній записується нескінченно, як 1/3 у десятковій. Тому в програмах, де рахують гроші, дробові числа намагаються не використовувати взагалі: суму зберігають у копійках цілим числом.

**Скільки типів у Python насправді.** Ми вивчили три, але їх набагато більше: логічний тип, списки, словники, множини, кортежі, комплексні числа. Частину з них ми пройдемо в цьому курсі. Хороша новина в тому, що всі вони поводяться за тими самими правилами: у кожного свій набір дозволених дій, і Python завжди чесно скаже, якщо ви попросите неможливе.

**Звідки взялася назва bool.** Тип названий на честь англійського математика Джорджа Буля, який у середині XIX століття описав алгебру з двох значень — істини й хиби. Тоді це виглядало чистою теорією без жодного застосування. Через сто років на цій алгебрі побудували всю обчислювальну техніку: кожен транзистор у процесорі — це фізичне втілення однієї булевої змінної.

**Чому саме `!=`, а не `<>`.** У старих мовах — Pascal, Basic — «не дорівнює» писали двома кутовими дужками. У мові C вибрали знак оклику як символ заперечення, і звідти він перейшов у більшість сучасних мов. У ранніх версіях Python `<>` теж працював, але його прибрали, щоб не було двох способів написати те саме.
