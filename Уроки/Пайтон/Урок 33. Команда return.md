## 2. Пояснення (8-10 хв)

### Блок 1. Команда return

`return` англійською — «повернути». Ця команда віддає результат туди, звідки функцію викликали.

Порівняємо дві версії однієї функції.

```
def площа_друк(a, b):
    print(a * b)

def площа(a, b):
    return a * b
```

Перша друкує. Друга повертає — і результат можна зберегти:

```
s = площа(5, 4)
print(s)                  → 20
print(s * 2)              → 40
print(площа(5, 4) + площа(3, 3))    → 29
```

З першою версією так не вийде. Вона нічого не віддає, а лише виводить на екран.

> 📝 **`return`** повертає результат туди, звідки функцію викликали.
> Результат можна зберегти у змінну й використати в обчисленнях: `s = площа(5, 4)`
> **`print` показує результат людині. `return` віддає його програмі.**

> ❓ **Яку версію функції взяти, якщо результат потрібен для подальших обчислень?**
>
> *Очікуємо:* ту, що з `return`.

### Блок 2. Найважливіша різниця

Це місце, де плутаються всі. Проговоримо його ще раз, бо різниця принципова.

| | `print` | `return` |
| --- | --- | --- |
| Куди йде результат | на екран | у програму |
| Чи можна зберегти | ні | так |
| Чи можна використати далі | ні | так |
| Хто бачить | людина | програма |

Найпоказовіший приклад:

```
def сума(a, b):
    print(a + b)

x = сума(2, 3)      → на екрані з'явиться 5
print(x)            → None
```

На екрані з'явилося `5`, тому здається, що все працює. Але у змінній `x` лежить `None` — «нічого». Функція вивела число, але нічого не повернула.

`None` — це спеціальне значення, яке Python підставляє, коли повертати нічого. Побачили `None` там, де чекали число — шукайте забутий `return`.

> 📝 **`None`** — значення «нічого». Функція без `return` повертає саме його.
> Якщо у змінній опинилось `None` замість числа — у функції забули `return`.

> ❓ **Функція друкує 5, а у змінній опинилося `None`. Що забули?**
>
> *Очікуємо:* команду `return`.

### Блок 3. return завершує функцію

Ще одна властивість: щойно виконався `return`, функція **одразу закінчується**. Усе, що написано після нього, не виконається.

```
def перевірка(n):
    return n * 2
    print("Цей рядок ніколи не виконається")
```

Це не недолік, а зручність. Завдяки цьому функція може вийти раніше, якщо відповідь уже зрозуміла:

```
def оцінка_словами(бал):
    if бал >= 10:
        return "Високий рівень"
    if бал >= 7:
        return "Достатній рівень"
    return "Потрібно попрацювати"
```

Тут `else` навіть не потрібен: якщо перший `return` спрацював, до другого справа не дійде.

> 📝 **`return` одразу завершує функцію.** Рядки після нього не виконуються.
> Функція може мати кілька `return` — спрацює той, до якого дійде виконання.

> ❓ **Скільки `return` може бути у функції?**
>
> *Очікуємо:* скільки завгодно, але спрацює лише один — той, до якого дійде виконання.

### Блок 4. Що можна повертати

Повертати можна що завгодно: число, текст, список, значення `True` чи `False`.

```
def парне(n):
    return n % 2 == 0

if парне(10):
    print("Так")
```

Тут функція повертає результат порівняння, тобто `True` або `False`, і її можна поставити прямо в умову.

Можна повернути й цілий список:

```
def парні_до(n):
    результат = []
    for i in range(2, n + 1, 2):
        результат.append(i)
    return результат
```

Правило вибору просте. Якщо функція щось **обчислює** — вона повертає. Якщо щось **оформлює** для людини — вона друкує. Змішувати в одній функції обидва завдання не варто.

> 📝 **Повертати можна що завгодно:** число, текст, `True`/`False`, список.
> Функція, яка **обчислює**, повертає результат. Функція, яка **оформлює**, друкує.

> ❓ **Функція рахує середній бал списку. Вона має друкувати чи повертати?**
>
> *Очікуємо:* повертати, бо вона обчислює.

#### ✅ Відповіді до бонусів

**Бонус 1.** може, через кому.
```
def мін_макс(числа):
    return min(числа), max(числа)

найменше, найбільше = мін_макс([4, 9, 2, 7])
print(найменше, найбільше)      → 2 9
```
Насправді Python пакує два значення в один набір, а при присвоюванні розкладає назад. Це той самий прийом, що в обміні значень `a, b = b, a` з уроку 6.

**Бонус 2.**
```
def просте(n):
    if n < 2:
        return False
    for d in range(2, n):
        if n % d == 0:
            return False
    return True
```
Головна ідея: щойно знайдено дільник, відповідь уже відома, і решту перевіряти не треба. `return` усередині циклу негайно завершує і цикл, і функцію. Для великих чисел це прискорює роботу в тисячі разів.

**Бонус 3.** На екрані з'явиться `5`, потім `None`, потім `5`. Перша п'ятірка — це друк усередині `сума1`. Далі `print(x)` дає `None`, бо `сума1` нічого не повертає, а функція без `return` повертає порожнє значення. І тільки `сума2` віддає результат назовні, тому `y` дорівнює 5. Правило: якщо результат треба **використати далі**, функція мусить його повертати, а не друкувати.

**Бонус 4.** Може, значення перелічують через кому.
```
def межі(числа):
    return max(числа), min(числа)

в, н = межі([7, 12, 9, 4])
print(в, н)
```
Виведе `12 4`. Насправді Python повертає одну пару значень, а рядок `в, н = ...` розкладає її по змінних — так само, як `a, b = input().split()`. Якщо записати результат в одну змінну, у ній опиниться вся пара цілком.

## 7. Якщо лишився час

**Найпоширеніша помилка початківців у світі.** Плутанина між `print` і `return` посідає перше місце в усіх списках типових помилок при вивченні програмування. Причина психологічна: на екрані все виглядає правильно, тому здається, що функція працює. Помилка виявляється лише тоді, коли результат треба використати далі. Саме тому на цю тему витрачають цілий урок.

**Чому функцію без return теж називають функцією.** Строго кажучи, це процедура — вона щось робить, але значення не дає. У деяких мовах, наприклад у Pascal, процедури й функції описують різними словами. Python їх не розрізняє: усе зветься функцією, а та, що нічого не повертає, повертає `None`.
