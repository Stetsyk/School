## 2. Пояснення (8-10 хв)

### Блок 1. Зріз

Зріз бере зі списку кілька елементів підряд. Записується двома індексами через двокрапку.

```
числа = [10, 20, 30, 40, 50, 60]
print(числа[1:4])      → [20, 30, 40]
```

Читається так: узяти з індексу 1 до індексу 4. І тут те саме правило, що в `range`: **права межа не входить**. Тому елемент з індексом 4 у зріз не потрапив.

Кількість елементів у зрізі легко порахувати: різниця індексів. `[1:4]` дає рівно три елементи.

Межі можна пропускати. Якщо не написати ліву — зріз почнеться з початку, якщо праву — дійде до кінця.

```
print(числа[:3])       → [10, 20, 30]     перші три
print(числа[3:])       → [40, 50, 60]     від четвертого до кінця
print(числа[-2:])      → [50, 60]         останні два
```

> 📝 **Зріз** — частина списку: `список[від:до]`
> **Права межа не входить.** `числа[1:4]` дає елементи з індексами 1, 2 і 3.
> `[:3]` — з початку · `[3:]` — до кінця · `[-2:]` — останні два

> ❓ **Скільки елементів дасть зріз `[2:7]`?**
>
> *Очікуємо:* п'ять.

### Блок 2. Крок і переворот

У зрізі, як і в `range`, можна вказати третє число — крок.

```
print(числа[::2])      → [10, 30, 50]     кожен другий
print(числа[::-1])     → [60, 50, 40, 30, 20, 10]   у зворотному порядку
```

Запис `[::-1]` варто запам'ятати окремо: це найкоротший спосіб перевернути список. Він працює і для рядків, у чому ми переконаємось на наступному уроці.

І найважливіше: **зріз створює новий список**, а початковий не змінює.

Саме тому зріз розв'язує проблему з уроку 24: щоб зробити справжню копію списку, пишуть `копія = список[:]`. Просте `копія = список` дає лише друге ім'я тому самому списку.

> 📝 **Крок у зрізі:** `[::2]` — кожен другий · `[::-1]` — у зворотному порядку
> **Зріз створює новий список.** Копія списку робиться так: `копія = список[:]`
> Запис `копія = список` копії **не** створює.

> ❓ **Як перевернути список у зворотний порядок одним записом?**
>
> *Очікуємо:* `список[::-1]`.

### Блок 3. Сортування

Упорядкувати список можна двома способами, і різниця між ними принципова.

**`sort()`** — метод, який упорядковує **сам список**. Нічого не повертає.

```
оцінки = [10, 7, 12, 9]
оцінки.sort()
print(оцінки)          → [7, 9, 10, 12]
```

**`sorted()`** — команда, яка **повертає новий** упорядкований список, а початковий лишає як був.

```
оцінки = [10, 7, 12, 9]
нові = sorted(оцінки)
print(нові)            → [7, 9, 10, 12]
print(оцінки)          → [10, 7, 12, 9]   не змінився
```

Найчастіша помилка теми — написати `оцінки = оцінки.sort()`. Метод `sort` нічого не повертає, тому у змінній опиниться порожнеча, і список загубиться.

Щоб відсортувати за спаданням, обом варіантам додають `reverse=True`:

```
оцінки.sort(reverse=True)          → [12, 10, 9, 7]
```

> 📝 **Два способи сортування:**
>
> | Запис | Що робить |
> | --- | --- |
> | `список.sort()` | сортує сам список, нічого не повертає |
> | `sorted(список)` | повертає новий список, початковий не чіпає |
> | `reverse=True` | сортувати за спаданням |
>
> **Помилка:** `список = список.sort()` — список буде втрачено.

> ❓ **Який спосіб узяти, якщо початковий порядок ще знадобиться?**
>
> *Очікуємо:* `sorted`, бо він не змінює початковий список.

### Блок 4. Сортування тексту

Списки слів сортуються за абеткою.

```
імена = ["Оля", "Андрій", "Марія"]
імена.sort()
print(імена)          → ['Андрій', 'Марія', 'Оля']
```

Але є тонкість: **великі літери йдуть перед малими**. Тому список `["яблуко", "Банан"]` відсортується як `["Банан", "яблуко"]` — не за абеткою, як очікує людина.

Причина в тому, що комп'ютер порівнює не літери, а їхні коди, а в кодах великі літери стоять раніше. Обійти це можна, вказавши, що порівнювати треба зведені до малих літер значення. Такий спосіб ми розберемо на уроці 35.

І ще: список зі змішаними типами відсортувати не можна. Якщо в ньому і числа, і текст, Python видасть `TypeError` — він не знає, що більше, п'ятірка чи слово.

> 📝 **Сортування тексту** йде за абеткою, але **великі літери стоять перед малими**.
> Список зі змішаними типами (числа й текст разом) відсортувати неможливо.

> ❓ **Як відсортується список `["дім", "Авто", "яблуко"]`?**
>
> *Очікуємо:* спершу `Авто` з великої літери, потім `дім` і `яблуко`.

#### ✅ Відповіді до бонусів

**Бонус 1.**
```
числа = [1, 2, 3, 4, 5, 6, 7]
середина = len(числа) // 2
print(числа[:середина])
print(числа[середина:])
```
Цілочисельне ділення потрібне тому, що індекс має бути цілим. При непарній довжині друга половина виявиться на один елемент довшою.

**Бонус 2.**
```
числа = [1, 2, 3, 2, 1]
if числа == числа[::-1]:
    print("Так, симетричний")
else:
    print("Ні")
```
Головна ідея: перевернутий зріз можна порівняти з початковим списком напряму, через `==`. Той самий прийом працює для слів-паліндромів, і саме його ми застосуємо на наступному уроці.

**Бонус 3.** Перший рядок **показує** перевернутий список, а сам список не чіпає. Другий **перевертає** сам список назавжди й нічого не виводить. Третій створює **новий** відсортований за спаданням список, лишаючи початковий недоторканим. Різниця між «показати», «змінити» і «створити новий» — головне, що треба тримати в голові під час роботи зі списками.

**Бонус 4.** Метод `.sort()` сортує список **на місці** й нічого не повертає, тому у `новий` потрапляє порожнє значення `None`. Правильно або відсортувати сам список і працювати з ним: `спис.sort()`, або взяти функцію, яка повертає новий список: `новий = sorted(спис)`. Правило легко запам'ятати: команди, що змінюють об'єкт на місці, зазвичай нічого не повертають, і `append` з `remove` поводяться так само.

## 7. Якщо лишився час

**Скільки способів сортувати.** Алгоритмів сортування придумано десятки, і в них досі є що вдосконалювати. Найпростіші — сортування вибором, яке ви робили в завданні 4, і бульбашкове, де сусідні елементи міняються місцями. Обидва повільні: для тисячі елементів вони роблять близько мільйона порівнянь. Швидші алгоритми справляються приблизно за десять тисяч, тобто в сто разів менше.

**Що всередині у Python.** Команда `sort` використовує алгоритм Timsort, створений у 2002 році спеціально для Python програмістом Тімом Пітерсом. Він виявився настільки вдалим, що його потім узяли Java, Android і браузери. Головна ідея — помічати шматки, які вже впорядковані, і не сортувати їх заново. У реальних даних такі шматки трапляються постійно.
