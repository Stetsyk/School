## 2. Пояснення (12-15 хв)

### Блок 1. Команда if

`if` англійською означає «якщо». Записується так:

```
if температура < 0:
    print("Одягни шапку!")
```

Читається просто: якщо в змінній `температура` лежить число менше нуля — вивести повідомлення. Якщо ні — цей рядок не виконається взагалі, програма просто піде далі.

У цьому записі є дві формальності, і обидві обов'язкові.

**Двокрапка** наприкінці рядка з умовою. Вона означає «а далі йде те, що треба зробити».

**Відступ** на початку наступного рядка. Чотири пробіли або одна клавіша Tab. Саме відступ показує, що цей рядок належить умові.

> 📝 **Команда розгалуження:**
>
> ```
> if умова:
>     дія
> ```
>
> Наприкінці рядка з умовою — **двокрапка**. Рядок із дією пишеться з **відступом**.
> Дія виконується тільки тоді, коли умова істинна.

> ❓ **У змінній `бал` лежить 5. Чи виконається `print` у програмі `if бал > 9: print("Молодець")`?**
>
> *Очікуємо:* ні, бо умова хибна.

### Блок 2. Відступ вирішує все

У більшості мов програмування межі блоку позначають дужками. У Python їх позначає відступ — і це унікальна риса мови.

Порівняйте дві програми:

```
if бал > 9:
    print("Відмінно!")
    print("Так тримати!")
```

```
if бал > 9:
    print("Відмінно!")
print("Так тримати!")
```

У першій **обидва** рядки належать умові — вони виконаються разом або не виконаються зовсім. У другій умові належить лише перший рядок, а другий виконається завжди, хоч би який був бал.

Різниця — чотири пробіли. Помилку такого роду знайти найважче, бо програма працює, просто робить не те.

> 📝 **Відступ визначає, що входить в умову.** Рядки з відступом виконуються лише при істинній умові, рядки без відступу — завжди.
> Відступ у Python — це чотири пробіли або Tab, і він має бути однаковим у всьому блоці.

> ❓ **Скільки рядків виконається при хибній умові в програмі, де під `if` стоять два рядки з відступом і один без?**
>
> *Очікуємо:* один — той, що без відступу.

### Блок 3. Що може бути умовою

Умовою є будь-який вираз, який дає `True` або `False`. Тобто все, що ми вивчали на уроці 5.

```
if вік >= 18:
if оцінка == 12:
if залишок != 0:
if n % 2 == 0:
if пароль == "12345":
```

Останні два варті окремої уваги. `n % 2 == 0` перевіряє парність: остача від ділення на два дорівнює нулю. А `пароль == "12345"` порівнює текст — і тут потрібні саме дві риски, бо одна поклала б значення у змінну замість перевірки.

> 📝 **Умовою може бути будь-яке порівняння:** `>`, `<`, `>=`, `<=`, `==`, `!=`.
> Перевірка парності: `if n % 2 == 0:`
> Порівняння тексту: `if пароль == "12345":`

> ❓ **Як записати умову «число ділиться на 5 без остачі»?**
>
> *Очікуємо:* `if n % 5 == 0:`


### Блок 4. Команда else

Спробуємо написати перевірку парності тим, що вже знаємо:

```
if n % 2 == 0:
    print("Парне")
if n % 2 != 0:
    print("Непарне")
```

Працює. Але умову довелося написати двічі, причому другий раз — навиворіт. А якщо вона буде довга на півтора рядки? А якщо потім вирішимо перевіряти не на 2, а на 3, і виправимо тільки в одному місці?

`else` англійською означає «інакше». Ставиться після блоку `if` і містить те, що робити, коли умова **хибна**.

```
n = int(input("Введіть число: "))
if n % 2 == 0:
    print("Парне")
else:
    print("Непарне")
```

Умова записана один раз. Ніякого «навиворіт» уже не потрібно.

Зверніть увагу на дві речі. По-перше, `else` пишеться **без умови** — після нього одразу двокрапка. По-друге, `else` стоїть на тому самому рівні, що й `if`, без відступу, а от його вміст — з відступом.

> 📝 **Розгалуження з двома гілками:**
>
> ```
> if умова:
>     дія 1
> else:
>     дія 2
> ```
>
> `else` записується **без умови**, лише з двокрапкою, і стоїть на одному рівні з `if`.

> ❓ **Чи може програма виконати обидві гілки одразу?**
>
> *Очікуємо:* ні. Виконається рівно одна — або перша, або друга.

### Блок 5. Рівно одна гілка

Це головна властивість `if-else`, і вона відрізняє його від двох окремих `if`.

Виконається **завжди рівно одна** гілка. Не жодної, не дві — рівно одна. Якщо умова істинна, працює перша, і друга навіть не перевіряється. Якщо хибна — навпаки.

Порівняйте на прикладі, де `n = 10`:

```
if n > 5:                if n > 5:
    print("A")               print("A")
if n > 8:                else:
    print("B")               print("B")
```

Ліворуч виведеться `A` і `B` — обидві умови істинні, обидва `if` спрацюють. Праворуч виведеться тільки `A`.

> 📝 **У розгалуженні `if-else` виконується рівно одна гілка.** Дві окремі команди `if` перевіряються незалежно й можуть спрацювати обидві.

> ❓ **При `n = 10` програма з `if n > 5` і `else` виведе одне повідомлення чи два?**
>
> *Очікуємо:* одне.

### Блок 6. Блок-схема розгалуження

Розгалуження зручно малювати схемою. Умова — ромб, з нього виходять дві стрілки з підписами «так» і «ні», і вони знову сходяться після розгалуження.

```
        ┌──────────────┐
        │  n % 2 == 0  │
        └──┬────────┬──┘
      так  │        │  ні
     ┌─────┘        └─────┐
┌────▼─────┐        ┌─────▼─────┐
│  Парне   │        │  Непарне  │
└────┬─────┘        └─────┬─────┘
     └────────┬───────────┘
       далі програма йде спільно
```

Схему малюють до того, як писати код, коли розгалужень багато й легко заплутатися. Це швидше, ніж переписувати програму.

> 📝 **Блок-схема розгалуження:** умова — ромб, з нього дві стрілки «так» і «ні», після гілок вони знову сходяться в одну.

> ❓ **Скільки стрілок виходить з ромба на блок-схемі розгалуження?**
>
> *Очікуємо:* дві — «так» і «ні».

### Блок 7. Типові задачі на дві гілки

Три задачі, які трапляються постійно.

**Парність.** `if n % 2 == 0` — парне, `else` — непарне.

**Більше з двох.** Порівнюємо й виводимо те, що більше.

```
if a > b:
    print("Більше:", a)
else:
    print("Більше:", b)
```

**Перевірка доступу.** Порівнюємо введене з правильним значенням.

```
пароль = input("Пароль: ")
if пароль == "сонце":
    print("Ласкаво просимо!")
else:
    print("Доступ заборонено")
```

> 📝 **Три типові задачі:** парність через `%` · більше з двох через порівняння · перевірка пароля через `==` з текстом.

> ❓ **Що виведе програма з прикладу про більше з двох, якщо `a` і `b` однакові?**
>
> *Очікуємо:* виведе `b`, бо умова `a > b` хибна й спрацює друга гілка. Для рівних чисел відповідь усе одно правильна.

## 3. Перевірка розуміння (4-6 хв)

1. **Що робить команда `if`?**
   Виконує дію тільки тоді, коли умова істинна.

2. **Що обов'язково ставлять наприкінці рядка з умовою?**
   Двокрапку.

3. **Навіщо потрібен відступ?**
   Він показує, які рядки належать умові.

4. **Що станеться з рядком без відступу після `if`?**
   Він виконається завжди, незалежно від умови.

5. **Як перевірити, чи число парне?**
   `if n % 2 == 0:`

6. **Що робить `else`?**
   Містить те, що виконується, коли умова хибна.

7. **Чи пишуть після `else` умову?**
   Ні, лише двокрапку.

8. **Скільки гілок виконається в розгалуженні `if-else`?**
   Рівно одна.

9. **Чим два окремі `if` відрізняються від `if-else`?**
   Окремі `if` перевіряються незалежно й можуть спрацювати обидва, у `if-else` спрацює тільки один.

10. **Як перевірити пароль?**
   Порівняти введений текст із правильним через `==`.

## 7. Якщо лишився час

**Чому саме відступи.** Автор Python свідомо зробив відступи обов'язковими. Логіка була така: у всіх мовах програмісти й так роблять відступи для читабельності, але при цьому мусять ще й ставити дужки. Виходить подвійна робота, і буває, що відступ показує одне, а дужки — інше, і код обманює читача. Python прибрав дужки й лишив тільки відступи. Спочатку це багатьох дратувало, зараз вважається однією з найкращих рис мови.

**Табуляція проти пробілів.** Це найвідоміша суперечка серед програмістів, про неї є жарти й навіть серіальна сцена. Python дозволяє і те, і те, але змішувати в одному файлі не можна — буде помилка. Загальна домовленість у світі Python: чотири пробіли. Більшість редакторів налаштовані так, що клавіша Tab сама вставляє чотири пробіли.

**Чому `else` не має умови.** Це не примха мови, а логіка: якщо умова `if` не виконалась, то вже точно виконалось протилежне, і повторювати його зайво. Більше того, повторення небезпечне: якщо ви напишете умову `else` вручну й помилитесь, з'явиться діапазон значень, за яких не виконається жодна гілка. Саме таку помилку колись знайшли в системі керування ліфтом.

**Розгалуження в процесорі.** Усередині процесора розгалуження — дорога операція. Процесор виконує команди наперед, ще не знаючи результату перевірки, тому він **вгадує**, яка гілка спрацює. Якщо вгадав — усе швидко, якщо ні — доводиться викидати зроблене й починати спочатку. Механізм так і називається — передбачувач переходів, і його точність у сучасних процесорах перевищує 95%.
