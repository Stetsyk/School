## 1. Вступ-гачок (2-3 хв)

У нас є список із двадцяти восьми оцінок класу. Треба порахувати середній бал.

Ми вже вміємо брати елементи за індексом. Значить, можна так:

```
сума = оцінки[0] + оцінки[1] + оцінки[2] + ... 
```

Двадцять вісім доданків в одному рядку. Довго, некрасиво, а головне — програма розсиплеться, щойно в класі з'явиться новий учень.

Але подумайте: що ми робимо, коли рахуємо суму на папері? Беремо оцінки **по одній** і додаємо. Одна дія, повторена двадцять вісім разів.

А повторювати ми вміємо ще з уроку 11.

І ще один борг. На уроці 12 ми зупинилися на задачі, яку не змогли розв'язати: порахувати, скільки оцінок вищі за середню. Середнє ставало відомим лише тоді, коли оцінки вже зникли. Тепер у нас є список — оцінки лежать і чекають, по них можна пройтися скільки завгодно разів.

Сьогодні поєднаємо цикли зі списками, а потім навчимося головного, що роблять зі списками: шукати в них потрібне. Це найважливіший урок усього модуля.

## 2. Пояснення (12-15 хв)

### Блок 1. Перебір елементів

Цикл `for` уміє йти прямо по списку, без жодного `range`.

```
оцінки = [10, 7, 11, 9]
for оцінка in оцінки:
    print(оцінка)
```

Читається як звичайне речення: для кожної оцінки зі списку оцінок — вивести її.

На кожному кроці змінна циклу отримує **наступний елемент списку**. Спершу 10, потім 7, потім 11, потім 9. Коли елементи закінчуються, цикл сам зупиняється.

Ім'я змінної вибираєте ви. Головне, щоб воно було осмисленим: `for оцінка in оцінки` читається краще, ніж `for x in оцінки`.

> 📝 **Перебір списку:**
>
> ```
> for елемент in список:
>     дія
> ```
>
> На кожному кроці змінна отримує наступний елемент. Цикл зупиняється сам, коли елементи закінчаться.

> ❓ **Скільки разів виконається тіло циклу `for оцінка in оцінки`, якщо в списку 12 елементів?**
>
> *Очікуємо:* дванадцять разів.

### Блок 2. Сума й середнє

Тепер поєднуємо перебір із накопичувачем з уроку 11. Схема та сама: обнулити до циклу, додавати всередині, вивести після.

```
оцінки = [10, 7, 11, 9]
сума = 0
for оцінка in оцінки:
    сума += оцінка
середнє = сума / len(оцінки)
print(f"Сума: {сума}, середнє: {середнє:.1f}")
```

Зверніть увагу: кількість елементів беремо через `len`, а не пишемо числом. Тоді програма працюватиме для списку будь-якої довжини — хоч із чотирьох оцінок, хоч із двадцяти восьми.

Саме тут списки й показують свою силу: одна й та сама програма без жодних змін обробляє будь-яку кількість даних.

> 📝 **Сума й середнє списку:**
>
> ```
> сума = 0
> for елемент in список:
>     сума += елемент
> середнє = сума / len(список)
> ```
>
> Кількість елементів беруть через `len`, а не пишуть числом.

> ❓ **Чому середнє ділять на `len(список)`, а не на конкретне число?**
>
> *Очікуємо:* щоб програма працювала для списку будь-якої довжини.

### Блок 3. Другий спосіб: перебір за індексами

Іноді всередині циклу потрібен не сам елемент, а його **номер** — наприклад, щоб вивести нумерований перелік. Тоді перебирають індекси.

```
пісні = ["Пісня А", "Пісня Б", "Пісня В"]
for i in range(len(пісні)):
    print(f"{i + 1}. {пісні[i]}")
```

Тут `range(len(пісні))` дає числа 0, 1, 2 — саме ті індекси, які існують у списку. А `пісні[i]` бере елемент за поточним індексом.

Виведеться:
```
1. Пісня А
2. Пісня Б
3. Пісня В
```

Одиниця в `i + 1` потрібна тому, що індекси йдуть з нуля, а люди рахують з одиниці.

| Спосіб | Коли брати |
| --- | --- |
| `for елемент in список` | потрібні лише значення |
| `for i in range(len(список))` | потрібні номери або треба змінювати елементи |

> 📝 **Перебір за індексами:**
>
> ```
> for i in range(len(список)):
>     print(список[i])
> ```
>
> Потрібен, коли в циклі знадобиться номер елемента або коли елементи треба змінювати.

> ❓ **Який спосіб узяти, щоб вивести список із нумерацією?**
>
> *Очікуємо:* перебір за індексами, бо потрібен номер.


### Блок 4. Готові команди

Для найчастіших задач у Python уже є готові команди.

```
оцінки = [10, 7, 11, 9, 12]
print(sum(оцінки))       → 49     сума всіх
print(max(оцінки))       → 12     найбільший
print(min(оцінки))       → 7      найменший
print(len(оцінки))       → 5      кількість
```

І два методи, які пишуть через крапку:

```
print(оцінки.count(10))   → 1     скільки разів трапляється 10
print(оцінки.index(11))   → 2     на якому місці стоїть 11
```

Середнє з готової команди не існує, але воно робиться в один рядок: `sum(оцінки) / len(оцінки)`.

> 📝 **Готові команди для списків:**
>
> | Команда | Що робить |
> | --- | --- |
> | `sum(список)` | сума всіх елементів |
> | `max(список)` | найбільший елемент |
> | `min(список)` | найменший елемент |
> | `len(список)` | кількість елементів |
> | `список.count(x)` | скільки разів трапляється `x` |
> | `список.index(x)` | індекс першого входження `x` |

> ❓ **Як одним рядком порахувати середній бал списку `оцінки`?**
>
> *Очікуємо:* `sum(оцінки) / len(оцінки)`.

### Блок 5. Пошук за умовою

Готові команди покривають прості випадки. Але щойно з'являється умова, потрібен цикл.

Наприклад, порахувати, скільки в списку оцінок вищих за 9. Це лічильник за умовою з уроку 12, тільки тепер він іде по списку:

```
кількість = 0
for оцінка in оцінки:
    if оцінка > 9:
        кількість += 1
print("Оцінок вище 9:", кількість)
```

Так само рахують суму лише підхожих значень — змінюється лише те, що додається.

> 📝 **Підрахунок за умовою:**
>
> ```
> кількість = 0
> for елемент in список:
>     if умова:
>         кількість += 1
> ```
>
> Збільшення лічильника стоїть **усередині `if`**.

> ❓ **Що зміниться в цій програмі, щоб рахувати не кількість, а суму таких оцінок?**
>
> *Очікуємо:* замість `кількість += 1` треба `сума += оцінка`.

### Блок 6. Відбір у новий список

Найкорисніший прийом теми. Якщо потрібні не лише кількість, а самі відібрані значення — їх збирають у **новий** список.

```
оцінки = [10, 7, 11, 9, 12, 5]
високі = []
for оцінка in оцінки:
    if оцінка > 9:
        високі.append(оцінка)
print(високі)      → [10, 11, 12]
```

Схема така сама, як у накопичувача: створити порожній список до циклу, наповнювати всередині, використовувати після.

Головна перевага цього прийому в тому, що початковий список не змінюється — з ним і далі можна працювати. І він розв'язує проблему, про яку ми говорили на уроці 15: видаляти елементи прямо під час перебору небезпечно, а зібрати потрібні в новий список — цілком безпечно.

> 📝 **Відбір у новий список:**
>
> ```
> відібрані = []
> for елемент in список:
>     if умова:
>         відібрані.append(елемент)
> ```
>
> Початковий список при цьому не змінюється.

> ❓ **Де створюють порожній список для відбору?**
>
> *Очікуємо:* до циклу, один раз.

### Блок 7. Пошук найбільшого вручну

Готовий `max` є, але корисно розуміти, як він працює всередині. Це той самий прийом із лідером, що на уроці 12, тільки початкове значення тепер беруть із самого списку:

```
найбільша = оцінки[0]
for оцінка in оцінки:
    if оцінка > найбільша:
        найбільша = оцінка
```

Тепер немає проблеми з від'ємними числами: за початкового лідера взято перший елемент, а він точно є серед даних.

Це знадобиться там, де готова команда не працює: наприклад, коли треба знайти не саме значення, а його **позицію** в списку.

```
найкраща = оцінки[0]
номер = 0
for i in range(len(оцінки)):
    if оцінки[i] > найкраща:
        найкраща = оцінки[i]
        номер = i
print(f"Найкраща оцінка {найкраща} стоїть на місці {номер + 1}")
```

> 📝 **Пошук найбільшого вручну:** за початкового лідера беруть **перший елемент списку**, потім порівнюють із ним решту.
> Якщо потрібна ще й позиція — перебирають індекси й запам'ятовують номер.

> ❓ **Чому за початкового лідера краще брати перший елемент, а не нуль?**
>
> *Очікуємо:* нуля може не бути серед даних, і для від'ємних чисел відповідь буде неправильна.

**Бонус 8.** Знайдіть **позицію** найбільшого елемента, а не саме значення. Що робити, якщо найбільших кілька?

#### ✅ Відповіді до бонусів

**Бонус 1.** потрібні два проходи — спершу порахувати середнє, і лише потім виводити різниці.
```
оцінки = [10, 7, 11, 9]
сума = 0
for о in оцінки:
    сума += о
середнє = сума / len(оцінки)
for о in оцінки:
    print(f"{о}: відхилення {о - середнє:+.1f}")
```
Головна ідея: середнє стає відомим лише після повного проходу, тому одним циклом задача не розв'язується. Знак `+` у форматуванні показує плюс для додатних чисел.

**Бонус 2.** цикл ніколи не закінчиться, бо список щоразу подовжується, і елементи не встигають закінчитися. Змінювати список під час перебору — одна з класичних помилок, і саме тому нові елементи зазвичай збирають в **окремий** список.

**Бонус 3.** Потрібен перебір за індексами, бо номер треба показати:
```
оцінки = [10, 7, 11, 9]
for i in range(len(оцінки)):
    print(i + 1, оцінки[i])
```
Прийом `i + 1` використовують щоразу, коли внутрішня нумерація з нуля має перетворитися на людську з одиниці.

**Бонус 4.** За один прохід це не робиться: поки список не пройдено, невідомо, яке значення найбільше. Тому проходів два.
```
числа = [7, 12, 9, 12, 4]
найбільше = числа[0]
for n in числа:
    if n > найбільше:
        найбільше = n
кількість = 0
for n in числа:
    if n == найбільше:
        кількість += 1
print(найбільше, кількість)
```
Це та сама логіка, що й із середнім: значення, яке залежить від усього списку, стає відомим лише після повного проходу.

**Бонус 5.**
```
імена = ["Оля", "Володимир", "Іван", "Катерина"]
найдовше = імена[0]
for імя in імена:
    if len(імя) > len(найдовше):
        найдовше = імя
print(найдовше)
```
Головна ідея: порівнюємо не самі значення, а результат обчислення над ними. Готовий `max` тут не підійде, бо він порівняв би імена за абеткою.

**Бонус 6.**
```
рух = [400, -120, 250, -90, 0, -35]
надходження = []
витрати = []
for n in рух:
    if n > 0:
        надходження.append(n)
    elif n < 0:
        витрати.append(n)
print(надходження, sum(надходження))
print(витрати, sum(витрати))
```
Надходження `[400, 250]` на 650 грн, витрати `[-120, -90, -35]` на −245 грн. Тут важливий `elif` замість другого `if`: нульова операція не потрапляє в жоден зі списків, і це правильно.

**Бонус 7.** Два проходи: спершу треба дізнатися середнє, і лише потім відбирати.
```
оцінки = [10, 7, 11, 9, 12, 4]
середнє = sum(оцінки) / len(оцінки)
кращі = []
for о in оцінки:
    if о > середнє:
        кращі.append(о)
print(середнє, кращі)
```
Середнє тут 8.83, тому в новий список потраплять 10, 11, 12 і 9.

**Бонус 8.** Разом із лідером запам'ятовують його номер:
```
числа = [7, 12, 9, 12, 4]
поз = 0
for i in range(len(числа)):
    if числа[i] > числа[поз]:
        поз = i
print(поз)
```
Виведе `1` — позицію **першого** з найбільших, бо умова строга `>`. Якщо потрібен останній, беруть `>=`. Якщо потрібні всі позиції, їх збирають у список другим проходом. Готова команда `числа.index(max(числа))` робить те саме, але теж повертає лише перше входження.

## 7. Якщо лишився час

**Чому Python обходиться без індексів.** У більшості старих мов список можна перебрати тільки за індексами, і код виглядає значно громіздкіше. Запис `for елемент in список` з'явився саме тому, що індекс у більшості задач не потрібен — потрібне значення. За статистикою, у реальних програмах на Python перший спосіб використовують приблизно вчетверо частіше за другий.

**Один прохід чи два.** Задача з бонусу 1 показує важливу річ: деякі задачі принципово вимагають двох проходів списком, бо результат першого потрібен у другому. Це не недолік, а властивість задачі. У програмуванні окремо цінують алгоритми, які встигають за один прохід, — вони швидші й потребують менше пам'яті.

**Чому вміти вручну все-таки потрібно.** Готова команда `max` знаходить найбільше число. Але щойно задача трохи змінюється — знайти найдовше слово, найкращого учня за середнім балом, найдорожчий товар зі знижкою — готової команди вже немає. Цикл же працює завжди, треба лише правильно записати умову. Саме тому в бонусі 1 `max` не допоміг.

**Скільки кроків робить пошук.** Щоб знайти найбільше число в списку зі ста елементів, треба переглянути всі сто — інакше можна пропустити потрібне. Це називають лінійним пошуком, і швидше в невпорядкованому списку не буває. Але якщо список **упорядкований**, працює двійковий пошук із уроку 14, і ста елементів вистачить сім кроків. Саме тому дані так часто тримають відсортованими — про сортування наступного уроку.
