## 1. Вступ-гачок (2-3 хв)

Черепашка малює як людина з олівцем: іде і лишає слід. Щоб намалювати квадрат, вона проходить чотири сторони.

Але спробуйте попросити її зробити просту річ: **посунути** намальований квадрат на десять кроків праворуч. Не вийде. Черепашка вміє малювати, а те, що вже намальовано, для неї просто пікселі на екрані. Стерти й перемалювати можна, посунути — ні.

А в іграх усе рухається постійно. М'яч летить, ракетка їздить, персонаж біжить.

Тому сьогодні ми беремо інший інструмент — **полотно**. На ньому фігури не малюють рухом, а ставлять одразу цілими: ось прямокутник, ось коло, ось лінія. І кожна фігура запам'ятовується, тому її можна буде посунути, перефарбувати або прибрати.

## 2. Пояснення (8-10 хв)

### Блок 1. Вікно з полотном

Полотно живе в модулі `tkinter` — тому самому, яким роблять вікна програм.

```
import tkinter

вікно = tkinter.Tk()
вікно.title("Малюємо на полотні")

полотно = tkinter.Canvas(вікно, width=600, height=400, bg="white")
полотно.pack()

вікно.mainloop()
```

Розберемо по рядках. `Tk()` створює вікно програми, `title` дає йому заголовок. `Canvas` створює полотно — білий прямокутник, на якому ми малюватимемо. `pack()` розміщує полотно у вікні: без нього полотна не буде видно.

Останній рядок `mainloop()` тримає вікно на екрані. Без нього вікно блимне й зникне — рівно так само, як turtle без `done()`.

Ці п'ять рядків будуть на початку кожної програми найближчих уроків.

> 📝 **Вікно з полотном:**
>
> ```
> import tkinter
> вікно = tkinter.Tk()
> полотно = tkinter.Canvas(вікно, width=600, height=400, bg="white")
> полотно.pack()
> вікно.mainloop()
> ```
>
> `mainloop()` пишуть **останнім рядком**, інакше вікно одразу зникне.

> ❓ **Що станеться, якщо забути рядок `полотно.pack()`?**
>
> *Очікуємо:* вікно з'явиться порожнім, полотна не буде видно.

### Блок 2. Координати полотна

Тут головна відмінність від усього, що ми знали.

У черепашки початок був у центрі екрана. У математиці вісь y росте вгору. **На полотні все інакше.**

Точка `(0, 0)` — це **лівий верхній кут**. Перше число `x` росте праворуч, друге число `y` росте **вниз**.

```
(0,0) ─────────────────► x
  │
  │        (300, 150)
  │             •
  │
  ▼ y
```

Тобто точка `(300, 150)` лежить на 300 пікселів праворуч і на 150 **вниз** від лівого верхнього кута.

Так зроблено не примхи заради: екран малюється зверху вниз, рядок за рядком, і рахувати від верхнього краю технічно природніше. Так само влаштовані координати у всіх графічних програмах.

Одиниця вимірювання — піксель, тобто одна точка екрана. Полотно 600 на 400 має 600 пікселів завширшки й 400 заввишки.

> 📝 **Координати полотна:** точка `(0, 0)` — **лівий верхній кут**.
> `x` росте праворуч, `y` росте **вниз**.
> Одиниця — піксель. Полотно 600×400 має 600 точок завширшки й 400 заввишки.

> ❓ **Де на полотні 600×400 буде точка `(0, 400)`?**
>
> *Очікуємо:* у лівому нижньому куті.

### Блок 3. Прямокутник і овал

Обидві фігури задаються **двома кутами уявного прямокутника**: спершу лівий верхній, потім правий нижній.

```
полотно.create_rectangle(50, 50, 200, 150, fill="yellow", outline="black", width=3)
```

Чотири числа — це `x1, y1, x2, y2`. Тобто лівий верхній кут у точці `(50, 50)`, правий нижній у точці `(200, 150)`. Ширина фігури виходить 150, висота 100.

Далі йдуть налаштування: `fill` — колір заливки, `outline` — колір контуру, `width` — товщина контуру.

Овал задається так само — чотирма числами того самого прямокутника, тільки фігура в нього вписується:

```
полотно.create_oval(50, 50, 200, 150, fill="red")
```

Щоб отримати **коло**, а не витягнутий овал, прямокутник має бути квадратним: ширина й висота однакові.

> 📝 **Прямокутник і овал** задаються двома кутами: `(x1, y1)` лівий верхній і `(x2, y2)` правий нижній.
>
> ```
> полотно.create_rectangle(50, 50, 200, 150, fill="yellow")
> полотно.create_oval(50, 50, 200, 150, fill="red")
> ```
>
> Овал вписується в цей прямокутник. Якщо він квадратний — вийде коло.
> Налаштування: `fill` заливка · `outline` контур · `width` товщина контуру.

> ❓ **Які чотири числа дадуть коло діаметром 100 у лівому верхньому куті полотна?**
>
> *Очікуємо:* `(0, 0, 100, 100)` — квадрат зі стороною 100.

### Блок 4. Лінія й текст

Лінія задається двома точками — початком і кінцем.

```
полотно.create_line(0, 0, 600, 400, fill="blue", width=2)
```

Точок може бути й більше — тоді вийде ламана:

```
полотно.create_line(50, 300, 150, 200, 250, 300, fill="green", width=3)
```

Текст ставлять у точку, і ця точка буде **центром** напису:

```
полотно.create_text(300, 30, text="Мій малюнок", font=("Arial", 20), fill="black")
```

Це знадобиться для підписів, рахунку в грі й будь-яких повідомлень прямо на полотні.

> 📝 **Лінія:** `create_line(x1, y1, x2, y2)`, точок може бути більше двох.
> **Текст:** `create_text(x, y, text="напис", font=("Arial", 20))` — точка є **центром** напису.

> ❓ **Скільки чисел потрібно, щоб намалювати ламану з трьох точок?**
>
> *Очікуємо:* шість, по два на кожну точку.

## 5. ⭐ Бонус для сильних

**Бонус 1.** Намалюйте шахову дошку 8 на 8 із клітинками по 50 пікселів.

**Бонус 2.** Намалюйте стовпчикову діаграму за списком чисел `[30, 80, 45, 120, 60]`.

**Бонус 3.** Намалюйте квадрат зі стороною 100 так, щоб його **центр** був у точці (200, 150). Які чотири числа треба передати в `create_rectangle`?

**Бонус 4.** Команда `create_oval` малює овал за прямокутником, у який він вписаний. Як намалювати **коло** радіуса 40 із центром у точці (200, 150)?

#### ✅ Відповіді до бонусів

**Бонус 1.** потрібні вкладені цикли з уроку 22 і перевірка парності.
```
for рядок in range(8):
    for стовпець in range(8):
        x = стовпець * 50
        y = рядок * 50
        if (рядок + стовпець) % 2 == 0:
            колір = "white"
        else:
            колір = "black"
        полотно.create_rectangle(x, y, x + 50, y + 50, fill=колір)
```
Головна ідея: координати обчислюються зі змінних циклу, а колір визначається парністю суми номерів рядка й стовпця.

**Бонус 2.**
```
дані = [30, 80, 45, 120, 60]
for i in range(len(дані)):
    x = 50 + i * 80
    полотно.create_rectangle(x, 350 - дані[i], x + 60, 350, fill="steelblue")
    полотно.create_text(x + 30, 365, text=str(дані[i]))
```
Найважче тут те, що стовпчики ростуть **угору**, а координата `y` росте вниз. Тому верх стовпчика обчислюється відніманням: `350 - висота`.

**Бонус 3.** Від центра відступають по половині сторони в кожен бік: `create_rectangle(150, 100, 250, 200)`. Загальне правило: `x - сторона/2`, `y - сторона/2`, `x + сторона/2`, `y + сторона/2`. Пам'ятайте, що на полотні вісь `y` спрямована **вниз**, тому менше значення `y` — це верхній край, а не нижній.

**Бонус 4.** `полотно.create_oval(160, 110, 240, 190)`. Прямокутник має бути квадратом, інакше вийде овал: від центра відступають радіус у всі чотири боки. Зручно одразу описати це функцією:
```
def коло(x, y, r, колір):
    полотно.create_oval(x - r, y - r, x + r, y + r, fill=колір)
```
Тоді коло малюється так, як його зазвичай і уявляють — центром і радіусом.

## 7. Якщо лишився час

**Чому y росте вниз.** Це спадщина перших дисплеїв. Електронний промінь у кінескопі малював зображення рядок за рядком, починаючи з верхнього лівого кута, — точно так, як ми читаємо текст. Кожен наступний рядок був нижчим, тому природно було нумерувати їх від нуля згори. Кінескопів давно немає, а система координат лишилася в усіх графічних бібліотеках світу.

**Що таке піксель.** Слово походить від англійського *picture element*, елемент зображення. Це одна точка екрана, і на сучасному телефоні їх близько трьох мільйонів. Цікаво, що фізичний розмір пікселя різний: на старому моніторі це помітна квадратна цятка, на телефоні око її не розрізняє.
