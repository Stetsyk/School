## 1. Вступ-гачок (2-3 хв)

Минулого разу квадрат зайняв у нас вісім рядків. Восьмикутник зайняв би шістнадцять. А фігура з тридцяти шести сторін — сімдесят два рядки.

Але подивіться на ці рядки уважно. Вони всі однакові: пройти вперед, повернути. Пройти вперед, повернути.

А що ми робимо, коли бачимо однакові рядки? Правильно, беремо цикл. І функцію, якщо цей шматок ще й знадобиться кілька разів.

Сьогодні все, що ми вчили в перших дев'яти модулях, раптом стане видимим. Цикл перетворить вісім рядків на два. Функція дасть змогу намалювати ліс із п'яти дерев трьома рядками. А `random` зробить кожен запуск програми несхожим на попередній.

## 2. Пояснення (8-10 хв)

### Блок 1. Багатокутник циклом

Квадрат — це чотири однакові кроки. Отже, цикл `range(4)`.

```
import turtle

for i in range(4):
    turtle.forward(100)
    turtle.right(90)

turtle.done()
```

Два рядки замість восьми. Але справжня сила в іншому: тепер кількість сторін легко зробити змінною.

```
сторін = 8
for i in range(сторін):
    turtle.forward(60)
    turtle.right(360 / сторін)
```

Змінили одне число — отримали іншу фігуру. Поставили 3 — трикутник, 5 — п'ятикутник, 36 — майже коло.

Кут при цьому не пишуть числом, а **обчислюють**: `360 / сторін`. Це те саме правило з минулого уроку, тільки тепер його рахує сама програма.

> 📝 **Правильний багатокутник циклом:**
>
> ```
> for i in range(сторін):
>     turtle.forward(довжина)
>     turtle.right(360 / сторін)
> ```
>
> Кут **обчислюють**, а не пишуть числом — тоді одна програма малює будь-яку фігуру.

> ❓ **Що намалює цей цикл при `сторін = 3`?**
>
> *Очікуємо:* рівносторонній трикутник із кутом повороту 120.

### Блок 2. Спіраль і розетка

Якщо всередині циклу щось поступово змінювати, з'являються складніші візерунки.

**Спіраль** виходить, коли кожен наступний крок довший за попередній. Довжину беруть просто зі змінної циклу:

```
for i in range(100):
    turtle.forward(i)
    turtle.right(91)
```

Зверніть увагу на 91, а не 90. Один зайвий градус змушує фігуру щоразу трохи зсуватися — і замість квадрата виходить спіраль, що закручується.

**Розетка** виходить, коли ту саму фігуру малюють кілька разів, щоразу повертаючи навколо центра. Тут потрібні вкладені цикли з уроку 22:

```
for k in range(12):              # 12 квадратів
    for i in range(4):           # кожен квадрат
        turtle.forward(80)
        turtle.right(90)
    turtle.right(30)             # поворот перед наступним
```

Зовнішній цикл рахує квадрати, внутрішній малює кожен. Кут повороту між ними — 360 поділити на кількість фігур, тобто 30.

> 📝 **Спіраль:** довжина кроку береться зі змінної циклу, кут трохи відрізняється від правильного.
> **Розетка:** вкладені цикли — зовнішній рахує фігури, внутрішній малює одну, між ними поворот на `360 / кількість`.

> ❓ **На скільки градусів повертати між фігурами, щоб зробити розетку з 8 квадратів?**
>
> *Очікуємо:* на 45.

### Блок 3. Власні функції-фігури

Тепер найкорисніше. Фігуру виносять у функцію з параметрами — і далі малюють одним рядком.

```
def квадрат(сторона, колір):
    turtle.fillcolor(колір)
    turtle.begin_fill()
    for i in range(4):
        turtle.forward(сторона)
        turtle.right(90)
    turtle.end_fill()
```

Викликати можна скільки завгодно разів:

```
квадрат(50, "red")
квадрат(80, "blue")
```

Але є важлива домовленість. Щоб фігури не залежали одна від одної, кожна функція має **повертати черепашку туди, звідки почала**, і в тому самому напрямку. У циклі з чотирьох кроків це виходить само собою: після чотирьох поворотів на 90 градусів черепашка дивиться в початковий бік.

Ще зручніше додати функції параметри координат:

```
def квадрат(x, y, сторона, колір):
    turtle.penup()
    turtle.goto(x, y)
    turtle.pendown()
    ...
```

Тоді фігуру можна поставити куди завгодно одним викликом.

> 📝 **Фігура у функції:** параметрами роблять розмір, колір і координати.
> Функція має **повертати черепашку в початкову точку й напрямок**, інакше наступна фігура з'явиться не там, де очікували.

> ❓ **Навіщо функції-фігурі параметри `x` і `y`?**
>
> *Очікуємо:* щоб малювати ту саму фігуру в різних місцях екрана.

### Блок 4. Випадковість у малюнку

Функції `random` з минулого уроку перетворюють будь-який малюнок на генератор.

```
import turtle
import random

кольори = ["red", "blue", "green", "orange", "purple"]

for i in range(30):
    turtle.penup()
    turtle.goto(random.randint(-300, 300), random.randint(-200, 200))
    turtle.pendown()
    turtle.pencolor(random.choice(кольори))
    квадрат(random.randint(20, 60), random.choice(кольори))
```

Кожен запуск дає нову картинку. Випадковими роблять координати, розміри, кольори, кути.

Одна практична порада: межі координат беріть із запасом, приблизно від −300 до 300 по горизонталі й від −200 до 200 по вертикалі. Якщо взяти більше, частина фігур опиниться за краєм екрана.

> 📝 **Випадковість у графіці:** випадковими роблять координати, розміри й кольори.
> Межі координат беруть у межах видимої частини екрана, приблизно −300…300 і −200…200.

> ❓ **Що станеться, якщо взяти координати від −1000 до 1000?**
>
> *Очікуємо:* частина фігур намалюється за межами вікна й буде невидимою.

#### ✅ Відповіді до бонусів

**Бонус 1.** потрібна функція, яка викликає сама себе — рекурсія, про яку ми згадували на уроці 31.
```
import turtle

def гілка(довжина):
    if довжина < 10:
        return
    turtle.forward(довжина)
    turtle.left(30)
    гілка(довжина * 0.7)
    turtle.right(60)
    гілка(довжина * 0.7)
    turtle.left(30)
    turtle.backward(довжина)

turtle.left(90)
гілка(100)
turtle.done()
```
Кожна гілка малює дві менші, і так поки вони не стануть закороткими. Умова `if довжина < 10: return` — це та сама умова зупинки, без якої рекурсія нескінченна.

**Бонус 2.**
```
for k in range(12):
    квадрат(30 + k * 5)
    turtle.right(30)
```
Головна ідея: розмір обчислюється зі змінної зовнішнього циклу. Той самий прийом, що у спіралі, тільки застосований до цілої фігури.

**Бонус 3.** Повертати на `360 / 8` = 45 градусів. Відрізків буде 8 × 4 = **32**.
```
import turtle
for і in range(8):
    for j in range(4):
        turtle.forward(100)
        turtle.right(90)
    turtle.right(45)
```
Головна умова, щоб розетка зійшлася: після внутрішнього циклу черепашка має стояти в тій самій точці й дивитися в тому самому напрямку, що й на початку.

**Бонус 4.** При 90 градусах кожні чотири кроки дають повний оберт 360, і черепашка повертається точно в початкову точку — далі вона просто обводить той самий квадрат. При 91 градусі оберт виходить 364, тобто на 4 градуси більше, і фігура щоразу трохи повертається відносно попередньої. Накладені одна на одну повернуті фігури й дають візерунок спіралі. Чим ближчий кут до правильного, тим повільніше закручується малюнок і тим більше витків потрібно.

## 7. Якщо лишився час

**Фрактали.** Дерево з бонусу 1 — це фрактал, фігура, кожна частина якої схожа на цілу. Такі форми трапляються в природі постійно: гілки дерев, річкові дельти, кровоносні судини, сніжинки, берегові лінії. Математик Бенуа Мандельброт, який описав фрактали у 1975 році, почав саме з питання «яка довжина берегової лінії Британії» — і виявив, що відповідь залежить від довжини лінійки.

**Чому один зайвий градус дає спіраль.** Якщо кут рівно 90, черепашка щоразу повертається в ту саму точку й малює квадрат поверх квадрата. Зайвий градус означає, що після чотирьох кроків вона не повернулась точно, а зсунулася на один градус, і наступний квадрат виходить трохи повернутим. Через сто кроків цих зсувів набирається на повне коло — і виходить розетка або спіраль.
