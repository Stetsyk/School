## 1. Вступ-гачок (2-3 хв)

Усі програми, які ми написали досі, мають одну спільну властивість: вони роблять те саме завжди. Запустили — виконались усі рядки згори вниз — закінчились.

А тепер подивіться на свій телефон. Коли заряду лишається мало, він сам пропонує ввімкнути економію, а коли заряду досить — мовчить. Навігатор попереджає, якщо ви їдете швидше, ніж дозволено. Касир на вході в кіно дивиться на вік і називає ціну квитка. Кожна з цих програм щомиті **щось вирішує**.

Думка в усіх однакова. **Якщо** заряду менше двадцяти відсотків — попередити, **інакше** — нічого не казати. Двох варіантів часто досить.

Але буває й більше. Світлофор не обходиться двома кольорами: **якщо** зелений — іди, **інакше якщо** жовтий — приготуйся, **інакше** — стій.

Сьогодні наша програма навчиться обом рішенням: спершу виберемо одне з двох, а потім одне з кількох. Це найбільший стрибок за весь курс, тому рухатися будемо уважно.

## 2. Пояснення (15-18 хв)

### Блок 1. Дві гілки: if і else

`if` англійською означає «якщо», `else` — «інакше». Почнемо одразу з повного рішення, де є обидві гілки:

```
заряд = 15
if заряд < 20:
    print("Підключіть зарядку")
else:
    print("Заряду вистачає")
```

Читається як звичайне речення: якщо в змінній `заряд` лежить число менше двадцяти — вивести перше повідомлення, інакше — друге. Зараз у змінній 15, тому на екрані з'явиться `Підключіть зарядку`. Змінимо перший рядок на `заряд = 64`, запустимо ще раз — і побачимо `Заряду вистачає`.

У цьому записі є три формальності, і всі обов'язкові.

**Двокрапка** наприкінці рядка з умовою і після `else`. Вона означає «а далі йде те, що треба зробити».

**Відступ** на початку рядків із діями. Чотири пробіли або одна клавіша Tab. Саме відступ показує, що рядок належить своїй гілці.

**`else` без умови.** Після нього одразу двокрапка. Умову не повторюють: якщо перша не виконалась, то вже точно виконалось протилежне. І стоїть `else` на тому самому рівні, що й `if`, без відступу.

> 📝 **Розгалуження з двома гілками:**
>
> ```
> if умова:
>     дія 1
> else:
>     дія 2
> ```
>
> Після умови й після `else` — **двокрапка**. Дії пишуться з **відступом**. `else` записується **без умови** й стоїть на одному рівні з `if`.

> ❓ **У змінній `заряд` лежить 20. Що виведе програма?**
>
> *Очікуємо:* `Заряду вистачає`, бо умова `20 < 20` хибна — знак строго «менше».

### Блок 2. Відступ вирішує все

У більшості мов програмування межі блоку позначають дужками. У Python їх позначає відступ — і це унікальна риса мови.

Порівняйте дві програми:

```
заряд = 64
if заряд < 20:
    print("Підключіть зарядку")
else:
    print("Заряду вистачає")
    print("Гарного дня!")
```

```
заряд = 64
if заряд < 20:
    print("Підключіть зарядку")
else:
    print("Заряду вистачає")
print("Гарного дня!")
```

У першій рядок `Гарного дня!` має відступ, тому належить гілці `else` і виведеться, лише коли заряду досить. У другій він без відступу, стоїть уже після розгалуження й виведеться завжди, хоч би який був заряд.

Різниця — чотири пробіли. Помилку такого роду знайти найважче, бо програма працює, просто робить не те.

> 📝 **Відступ визначає, що входить у гілку.** Рядки з відступом виконуються лише разом зі своєю гілкою, рядки без відступу після розгалуження — завжди.
> Відступ у Python — це чотири пробіли або Tab, і він має бути однаковим у всьому блоці.

> ❓ **У першій програмі змінили перший рядок на `заряд = 5`. Скільки рядків виведеться?**
>
> *Очікуємо:* один — `Підключіть зарядку`. Обидва рядки під `else` пропускаються.

### Блок 3. Що може бути умовою

Умовою є будь-який вираз, який дає `True` або `False`. Тобто все, що ми вивчали на уроці 5.

```
if вік >= 18:
if оцінка == 12:
if гроші < ціна:
if кількість != 0:
if пароль == "сонце":
```

Останній рядок вартий окремої уваги. Текст теж можна порівнювати, і тут потрібні саме дві риски. Одна риска поклала б значення у змінну замість перевірки, і Python видасть помилку.

> 📝 **Умовою може бути будь-яке порівняння:** `>`, `<`, `>=`, `<=`, `==`, `!=`.
> Порівнювати можна й числа, і текст: `if пароль == "сонце":`
> Для перевірки завжди **дві** риски.

> ❓ **Як записати умову «грошей вистачає на покупку»?**
>
> *Очікуємо:* `if гроші >= ціна:`

### Блок 4. Рівно одна гілка

Це головна властивість `if-else`, і вона відрізняє його від двох окремих `if`.

Виконається **завжди рівно одна** гілка. Не жодної, не дві — рівно одна. Якщо умова істинна, працює перша, і друга навіть не перевіряється. Якщо хибна — навпаки.

Порівняйте на прикладі, де `температура = 25`:

```
if температура > 15:          if температура > 15:
    print("Тепло")                print("Тепло")
if температура > 20:          else:
    print("Спекотно")             print("Прохолодно")
```

Ліворуч виведеться `Тепло` і `Спекотно` — обидві умови істинні, обидва `if` спрацюють, бо кожен перевіряється сам по собі. Праворуч виведеться тільки `Тепло`.

Іноді для «інакше» робити нічого не треба. Тоді `else` просто не пишуть:

```
сума = 800
if сума > 500:
    print("Ви отримали знижку 10%")
    сума = сума * 0.9
print("До сплати:", сума)
```

Без знижки програма просто йде далі й виводить суму як є.

> 📝 **У розгалуженні `if-else` виконується рівно одна гілка.** Дві окремі команди `if` перевіряються незалежно й можуть спрацювати обидві.
> `else` можна не писати, коли для «інакше» нема чого робити.

> ❓ **При `температура = 25` програма праворуч виведе одне повідомлення чи два?**
>
> *Очікуємо:* одне.

### Блок 5. Коли варіантів більше двох: elif

Світлофор має три кольори, і двох гілок тут замало. Для третьої й наступних у Python є `elif` — скорочення від «else if», тобто «інакше якщо»:

```
колір = "жовтий"
if колір == "зелений":
    print("Можна йти")
elif колір == "жовтий":
    print("Приготуйся")
else:
    print("Стій!")
```

Python ставить питання по черзі. Зелений? Ні. Тоді, може, жовтий? Так — виводить `Приготуйся` і на цьому зупиняється. Якби не підійшла жодна умова, спрацював би `else`.

Будова така: спершу обов'язково один `if`, потім скільки завгодно `elif`, кожен зі своєю умовою, і наприкінці необов'язковий `else` для всіх решти випадків. Усі гілки стоять на одному рівні.

> 📝 **Ланцюжок умов:**
>
> ```
> if умова1:
>     дія1
> elif умова2:
>     дія2
> elif умова3:
>     дія3
> else:
>     дія для решти
> ```
>
> `elif` — «інакше якщо», і в нього, на відміну від `else`, **є умова**. Спершу завжди `if`, наприкінці необов'язковий `else`.

> ❓ **Що виведе програма, якщо в першому рядку написати `колір = "синій"`?**
>
> *Очікуємо:* `Стій!` — жодна умова не підійшла, тому спрацював `else`.

### Блок 6. Згори вниз до першої істинної

Найважливіше про ланцюжок: Python перевіряє умови **згори вниз** і, щойно знаходить істинну, виконує її гілку й **пропускає весь залишок**. Тому навіть з `elif` виконується рівно одна гілка.

```
заряд = 8
if заряд < 10:
    print("Терміново на зарядку!")
elif заряд < 30:
    print("Час шукати розетку")
else:
    print("Заряду вистачає")
```

При заряді 8 істинні обидві перші умови: і `8 < 10`, і `8 < 30`. Але виведеться тільки `Терміново на зарядку!` — до другої умови Python просто не дійде.

Звідси наслідок, на якому спотикаються всі. Поміняймо перші дві умови місцями:

```
if заряд < 30:
    print("Час шукати розетку")
elif заряд < 10:
    print("Терміново на зарядку!")
```

Тепер при заряді 8 виведеться `Час шукати розетку`. А `Терміново на зарядку!` не виведеться ніколи: кожне число, менше за 10, менше й за 30, тож його завжди перехопить перша умова.

> 📝 **Умови в ланцюжку перевіряються згори вниз.** Виконується гілка **першої істинної** умови, решта не перевіряються.
> Тому порядок важливий: умови ставлять **від найвужчої до найширшої**.

> ❓ **У ланцюжку для квитків першою стоїть умова `вік < 18`, а другою `вік < 7`. Що не так?**
>
> *Очікуємо:* друга гілка ніколи не спрацює, бо всіх молодших за 7 уже перехопила перша умова. `вік < 7` треба поставити першою.

### Блок 7. Блок-схема розгалуження

Розгалуження зручно малювати схемою. Умова — ромб, з нього виходять дві стрілки з підписами «так» і «ні», і після гілок вони знову сходяться.

```
         ┌──────────────┐
         │  заряд < 20  │
         └──┬────────┬──┘
       так  │        │  ні
      ┌─────┘        └─────┐
┌─────▼──────┐     ┌───────▼──────┐
│ Підключіть │     │   Заряду     │
│  зарядку   │     │  вистачає    │
└─────┬──────┘     └───────┬──────┘
      └────────┬───────────┘
        далі програма йде спільно
```

Ланцюжок з `elif` — це кілька ромбів один під одним. Стрілка «ні» з одного ромба веде до наступного, а стрілка «так» — одразу до дії.

```
┌──────────────┐ так  ┌───────────┐
│ колір зелений├─────►│ Можна йти │──┐
└──────┬───────┘      └───────────┘  │
       │ ні                          │
┌──────▼───────┐ так  ┌────────────┐ │
│ колір жовтий ├─────►│ Приготуйся │─┤
└──────┬───────┘      └────────────┘ │
       │ ні                          │
┌──────▼───────┐                     │
│    Стій!     │─────────────────────┤
└──────────────┘                     ▼
                         далі програма
```

Схему малюють до того, як писати код, коли розгалужень багато й легко заплутатися. Це швидше, ніж переписувати програму.

> 📝 **Блок-схема розгалуження:** умова — ромб, з нього дві стрілки «так» і «ні», після гілок вони сходяться в одну. Кожен `elif` — ще один ромб на стрілці «ні».

> ❓ **Скільки ромбів буде на блок-схемі світлофора з трьома кольорами?**
>
> *Очікуємо:* два. Третій колір — це `else`, для нього перевірка не потрібна.

## 3. Перевірка розуміння (4-6 хв)

1. **Що роблять `if` і `else`?**
   `if` виконує дію, коли умова істинна, `else` — коли хибна.

2. **Що обов'язково ставлять наприкінці рядка з умовою і після `else`?**
   Двокрапку.

3. **Навіщо потрібен відступ?**
   Він показує, які рядки належать гілці.

4. **Що станеться з рядком без відступу після розгалуження?**
   Він виконається завжди, незалежно від умови.

5. **Чи пишуть після `else` умову?**
   Ні, лише двокрапку.

6. **Скільки гілок виконається в розгалуженні `if-else`?**
   Рівно одна.

7. **Чим два окремі `if` відрізняються від `if-else`?**
   Окремі `if` перевіряються незалежно й можуть спрацювати обидва, у `if-else` спрацює тільки один.

8. **Коли потрібен `elif`?**
   Коли варіантів більше двох.

9. **Чим `elif` відрізняється від `else`?**
   У `elif` є своя умова, а `else` ловить усе, що лишилося.

10. **Якщо в ланцюжку істинні дві умови, які гілки виконаються?**
    Лише гілка першої істинної умови.

## 7. Якщо лишився час

**Чому саме відступи.** Автор Python свідомо зробив відступи обов'язковими. Логіка була така: у всіх мовах програмісти й так роблять відступи для читабельності, але при цьому мусять ще й ставити дужки. Виходить подвійна робота, і буває, що відступ показує одне, а дужки — інше, і код обманює читача. Python прибрав дужки й лишив тільки відступи. Спочатку це багатьох дратувало, зараз вважається однією з найкращих рис мови.

**Табуляція проти пробілів.** Це найвідоміша суперечка серед програмістів, про неї є жарти й навіть серіальна сцена. Python дозволяє і те, і те, але змішувати в одному файлі не можна — буде помилка. Загальна домовленість у світі Python: чотири пробіли. Більшість редакторів налаштовані так, що клавіша Tab сама вставляє чотири пробіли.

**Чому `elif`, а не `else if`.** У багатьох мовах, наприклад у JavaScript, так і пишуть: `else if`. У Python це дало б проблему: після `else:` новий `if` довелося б писати з відступом, і кожен наступний варіант відсувався б ще правіше, як сходинки. Злите слово `elif` тримає весь ланцюжок на одному рівні.

**Розгалуження в процесорі.** Усередині процесора розгалуження — дорога операція. Процесор виконує команди наперед, ще не знаючи результату перевірки, тому він **вгадує**, яка гілка спрацює. Якщо вгадав — усе швидко, якщо ні — доводиться викидати зроблене й починати спочатку. Механізм так і називається — передбачувач переходів, і в сучасних процесорах він вгадує в переважній більшості випадків.
