## 2. Пояснення (8-10 хв)

### Блок 1. Зміна елемента

Найпростіше — записати нове значення в наявну комірку. Для цього до елемента за індексом застосовують звичайне присвоювання.

```
оцінки = [10, 7, 11]
оцінки[1] = 12
print(оцінки)      → [10, 12, 11]
```

Стара сімка зникла назавжди, як і при звичайному присвоюванні змінній.

Це працює тільки для індексів, які вже існують. Записати щось в `оцінки[5]`, коли елементів три, не вийде — буде `IndexError`.

> 📝 **Зміна елемента:** `список[індекс] = нове значення`
> Працює лише для індексів, які вже існують.

> ❓ **Список `[5, 8, 3]`. Що буде після `список[0] = 100`?**
>
> *Очікуємо:* `[100, 8, 3]`.

### Блок 2. Додавання елементів

Дві команди, і різниця між ними в тому, куди саме потрапляє нове значення.

**`append`** дописує в кінець списку.

```
покупки = ["хліб", "молоко"]
покупки.append("сир")
print(покупки)      → ['хліб', 'молоко', 'сир']
```

**`insert`** вставляє на вказану позицію, а всі наступні елементи зсуваються праворуч.

```
покупки.insert(0, "яйця")
print(покупки)      → ['яйця', 'хліб', 'молоко', 'сир']
```

Зверніть увагу на новий запис: команда пишеться **після** імені списку через крапку. Такі команди називають методами — вони належать саме спискам, а не Python узагалі.

> 📝 **Додавання:**
> `список.append(значення)` — додати в кінець
> `список.insert(індекс, значення)` — вставити на позицію, решту зсунути
> Команди після імені списку через крапку називають **методами**.

> ❓ **Чим `append` відрізняється від `insert`?**
>
> *Очікуємо:* `append` завжди додає в кінець, `insert` — на вказане місце.

### Блок 3. Видалення елементів

Тут теж є вибір, і залежить він від того, що ви знаєте: значення чи його місце.

**`remove`** видаляє за **значенням** — перше знайдене.

```
покупки.remove("молоко")
```

Якщо такого значення в списку немає, буде помилка. А якщо їх кілька — зникне тільки перше.

**`pop`** видаляє за **індексом** і повертає видалене значення.

```
останній = покупки.pop()      # без індексу — видаляє останній
перший = покупки.pop(0)       # з індексом — видаляє вказаний
```

> 📝 **Видалення:**
> `список.remove(значення)` — видалити перший елемент із таким значенням
> `список.pop(індекс)` — видалити за індексом і повернути його
> `список.pop()` без індексу видаляє останній елемент.

> ❓ **У списку два однакові значення. Скільки видалить `remove`?**
>
> *Очікуємо:* одне, перше знайдене.

### Блок 4. Перевірка наявності

Перед видаленням корисно переконатися, що елемент узагалі є. Для цього існує оператор `in` — він дає `True` або `False`.

```
if "молоко" in покупки:
    покупки.remove("молоко")
else:
    print("Такого товару в списку немає")
```

Той самий оператор зручний і сам по собі, для будь-яких перевірок:

```
if відповідь in ["так", "Так", "ТАК"]:
    print("Зараховано")
```

Це саме той короткий спосіб, який ми обіцяли на уроці 17 замість довгого ланцюжка з `or`.

> 📝 **Оператор `in`** перевіряє, чи є значення в списку, і дає `True` або `False`.
> `if "молоко" in покупки:`
> Заміняє довгий ланцюжок перевірок через `or`.

> ❓ **Що дасть `5 in [1, 2, 3]`?**
>
> *Очікуємо:* False.

#### ✅ Відповіді до бонусів

**Бонус 1.**
```
числа = [1, 5, 3, 5, 7, 5]
while 5 in числа:
    числа.remove(5)
print(числа)
```
Тут `while` працює доти, доки значення ще залишається в списку. Одного `remove` мало, бо він видаляє лише перше входження.

**Бонус 2.** `[2, 4]`. Після першого `pop` список став `[2, 3, 4]`, і елемент з індексом 1 — це вже трійка, а не двійка. Індекси зсуваються після кожного видалення, і саме через це видаляти елементи в циклі за індексами дуже небезпечно.

**Бонус 3.** Лишилося дві: `remove` прибирає тільки **перше** входження. Щоб видалити всі, повторюють, поки значення ще є:
```
while 5 in спис:
    спис.remove(5)
```
Робити те саме циклом `for` по цьому ж списку не можна: список коротшає під час перебору, і частина елементів пропускається.

**Бонус 4.** Виведе `[1, 2, 3, 4]`. Рядок `b = a` **не створює** новий список: обидва імені вказують на один і той самий список у пам'яті, тому зміна через `b` видно й через `a`. Щоб отримати справжню копію, пишуть `b = list(a)`. Це одна з найпоширеніших причин загадкових помилок зі списками, і саме тому важливо розрізняти «дати друге ім'я» і «зробити копію».

## 7. Якщо лишився час

**Чому команди пишуть через крапку.** Запис `покупки.append("сир")` читається як «списку покупки скажи: додай сир». Крапка означає, що команда належить саме цьому об'єкту. Такі команди називають методами, і в цьому запису схована ціла ідея, на якій побудовано сучасне програмування. Ми повернемось до неї на останньому уроці курсу.

**Черга і стек.** Списки, які змінюються, лежать в основі двох найважливіших структур в інформатиці. Черга працює як черга в магазині: додаємо в кінець, беремо з початку. Стек — як стос тарілок: і кладемо, і беремо зверху. Обидві робляться зі звичайного списку двома методами: `append` разом із `pop(0)` дає чергу, а `append` разом із `pop()` дає стек.
