## 2. Пояснення (8-10 хв)

### Блок 1. range із двома числами

Досі ми писали `range(n)` — від нуля до n−1. Якщо вказати два числа, перше стає початком, а друге — межею.

```
for i in range(1, 6):
    print(i)
```

Виведе: `1 2 3 4 5`.

Головне правило: **права межа не входить**. `range(1, 6)` дає числа від 1 до 5, а не до 6. Щоб отримати числа від 1 до 20, треба писати `range(1, 21)`.

Виглядає незручно, але так зроблено спеціально: різниця між числами відразу дає кількість повторень. `range(1, 21)` — це рівно 20 кроків.

> 📝 **`range(старт, стоп)`** дає числа від `старт` до `стоп − 1`.
> **Права межа не входить.** Щоб отримати числа від 1 до 20, пишуть `range(1, 21)`.

> ❓ **Які числа дасть `range(3, 7)`?**
>
> *Очікуємо:* 3, 4, 5, 6.

### Блок 2. Крок

Третє число в `range` задає крок — на скільки збільшувати змінну щоразу.

```
for i in range(0, 21, 5):
    print(i)
```

Виведе: `0 5 10 15 20`.

Крок може бути й від'ємним — тоді цикл рахує назад. Але тоді старт має бути більшим за стоп:

```
for i in range(10, 0, -1):
    print(i)
print("Пуск!")
```

Виведе зворотний відлік від 10 до 1, а потім `Пуск!`.

> 📝 **`range(старт, стоп, крок)`** — третє число задає крок.
> `range(0, 21, 5)` дає 0, 5, 10, 15, 20
> `range(10, 0, -1)` рахує назад: 10, 9, …, 1

> ❓ **Як вивести всі парні числа від 0 до 100?**
>
> *Очікуємо:* `for i in range(0, 101, 2):`

### Блок 3. Накопичувач у циклі

Тепер найголовніше на уроці. Накопичувач — це змінна з уроку 5, яка збирає суму, тільки тепер вона працює всередині циклу.

```
сума = 0
for i in range(1, 101):
    сума += i
print("Сума:", сума)
```

Три рядки, і задача Гаусса розв'язана. Результат — 5050.

Схема завжди однакова, і в ній три частини:

1. **обнулити** накопичувач — до циклу
2. **додавати** до нього в тілі циклу
3. **вивести** результат — після циклу

Найчастіша помилка теми — поставити обнулення всередину циклу. Тоді накопичувач скидається щоразу, і в кінці лишається тільки останнє значення.

```
сума = 0                    сума = 0
for i in range(1, 5):       for i in range(1, 5):
    сума += i                   сума = 0          ← помилка
print(сума)   → 10              сума += i
                            print(сума)   → 4
```

> 📝 **Схема накопичувача:**
>
> ```
> сума = 0                 ← обнулити ДО циклу
> for i in range(1, 101):
>     сума += i            ← додавати всередині
> print(сума)              ← вивести ПІСЛЯ циклу
> ```
>
> Обнулення всередині циклу — найчастіша помилка теми.

> ❓ **Що станеться, якщо рядок `сума = 0` поставити всередину циклу?**
>
> *Очікуємо:* сума скидатиметься на кожному кроці, і в кінці залишиться лише останнє додане число.

### Блок 4. Не тільки сума

Той самий прийом працює для будь-якого накопичення. Змінюється лише дія і початкове значення.

**Добуток.** Починається з одиниці, а не з нуля — бо на нуль усе перемножиться в нуль.

```
добуток = 1
for i in range(1, 6):
    добуток *= i
print(добуток)      → 120
```

Це факторіал числа 5 — добуток усіх чисел від 1 до 5.

**Текст.** Накопичувати можна й рядки, починаючи з порожнього.

```
рядок = ""
for i in range(1, 6):
    рядок += "*"
print(рядок)        → *****
```

> 📝 **Початкове значення накопичувача залежить від дії:**
> для суми — `0` · для добутку — `1` · для тексту — `""`

> ❓ **Чому накопичувач добутку не можна починати з нуля?**
>
> *Очікуємо:* тоді все помножиться на нуль і результатом буде нуль.

#### ✅ Відповіді до бонусів

**Бонус 1.** 234168.
```
сума = 0
for i in range(1, 1001):
    if i % 3 == 0 or i % 5 == 0:
        сума += i
print(сума)
```
Головна пастка: числа, які діляться і на 3, і на 5, не можна рахувати двічі. Тут це вирішується автоматично, бо `or` перевіряє одне число один раз.

**Бонус 2.** 15 разів, останнє значення 99. Перевірити можна накопичувачем-лічильником або обчисленням: від 1 з кроком 7 до межі 100 виходить ряд 1, 8, 15, …, 99.

**Бонус 3.** `for i in range(10, 0, -1):` і всередині `print(i)`. Якщо забути крок і написати `range(10, 0)`, цикл не виконається **жодного разу**: за замовчуванням крок дорівнює 1, а від 10 з кроком 1 до нуля дійти неможливо. Помилки при цьому не буде, програма просто мовчки нічого не зробить.

**Бонус 4.** Числа від 14 до 98, їх тринадцять, сума **728**.
```
сума = 0
for i in range(14, 99, 7):
    сума += i
print(сума)
```
Зверніть увагу на межу 99, а не 98: права межа в `range` не входить, тому останнє число 98 треба «накрити» більшим значенням.

## 7. Якщо лишився час

**Чи справді Гаусс це зробив.** Історію про дев'ятирічного Гаусса переказують у сотні варіантів, і достеменно невідомо, які саме числа він додавав. Але формула, яку він вивів, справжня: сума чисел від 1 до n дорівнює n помножити на n+1 і поділити на 2. Для сотні це 100 на 101 поділити на 2, тобто 5050. Перевірте вашою програмою — збігається.

**Коли формула краща за цикл.** Наша програма робить сто кроків, формула — одну дію. Для сотні різниці немає, а для мільярда цикл рахуватиме кілька секунд, тоді як формула дасть відповідь миттєво. Тому в програмуванні цінують не тільки правильний результат, а й кількість дій, потрібних для його отримання.
