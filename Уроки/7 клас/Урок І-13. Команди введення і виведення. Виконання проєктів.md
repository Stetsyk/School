## 1. Вступ-гачок (2-3 хв)

На минулому уроці ми написали програму, яка рахує площу прямокутника:

```
a = 6
b = 4
S = a * b
print("Площа:", S)
```

Вона працює. Але є проблема: вона вміє рахувати площу тільки прямокутника 6 на 4. Для іншого прямокутника доводиться лізти в текст програми й міняти числа.

Уявіть, що калькулятор на телефоні працював би так: щоб порахувати `7 + 3`, треба відкрити його вихідний код і переписати рядок. Ним би ніхто не користувався.

Справжня програма не містить чисел усередині. Вона їх **запитує**. Сьогодні навчимося писати саме такі — і зрозуміємо, чому найпоширеніша помилка новачків виглядає як `53` замість `8`.

## 2. Пояснення (8-10 хв)

### Блок 1. Команда введення `input`

Щоб програма запитала дані в користувача, є команда `input`.

```
ім_я = input("Як тебе звати? ")
print("Привіт,", ім_я)
```

Що відбувається по кроках: на екрані з'являється текст `Як тебе звати?`, програма зупиняється й чекає. Користувач набирає щось на клавіатурі й натискає Enter. Те, що він набрав, потрапляє у змінну `ім_я`. Далі програма йде далі.

Текст у дужках — це **підказка**. Вона не обов'язкова, але без неї користувач бачить порожній екран і не розуміє, чого від нього хочуть. Тому підказку пишуть завжди, і в кінці ставлять пробіл — щоб набране не злипалося з питанням.

> 📝 **Команда введення:** `змінна = input("підказка")`
> Програма показує підказку, чекає, поки користувач набере текст і натисне Enter, і кладе набране у змінну.

> ❓ **Програма запустилась і завмерла з порожнім екраном. Що забув програміст?**
>
> *Очікуємо:* підказку в дужках `input` — користувач не знає, чого від нього чекають.

### Блок 2. Головна пастка: `input` завжди дає текст

А тепер найважливіше на сьогодні.

**Команда `input` завжди повертає текст, навіть якщо користувач набрав число.**

Подивіться, що з цього виходить:

```
a = input("Перше число: ")
b = input("Друге число: ")
print(a + b)
```

Користувач вводить `5` і `3`. Програма виводить... `53`.

Помилки тут немає. Python отримав не числа, а два **текстові** значення — `"5"` і `"3"`. А знак `+` для тексту означає не додавання, а склеювання: `"5"` і `"3"` склеюються в `"53"`. Так само `"при"` + `"віт"` дало б `"привіт"`.

Щоб отримати саме число, введене значення треба **перетворити**:
- `int(...)` — перетворює на ціле число
- `float(...)` — перетворює на число з дробовою частиною.

Правильний варіант:

```
a = int(input("Перше число: "))
b = int(input("Друге число: "))
print(a + b)
```

Тепер буде `8`.

Читати такий рядок треба зсередини назовні: спершу `input` бере текст, потім `int` перетворює його на число, і аж тоді результат кладеться у змінну.

> 📝 **`input` завжди повертає текст.** Щоб отримати число, його треба перетворити:
> `n = int(input("..."))` — ціле число
> `x = float(input("..."))` — число з дробовою частиною
> Для тексту `+` означає склеювання: `"5" + "3"` дає `"53"`.

> ❓ **Користувач ввів 20 і 5, а програма вивела `205`. Що треба додати в код?**
>
> *Очікуємо:* перетворення `int(...)` навколо кожного `input`, бо зараз складається текст, а не числа.

### Блок 3. Команда виведення `print`

`print` ми вже використовували, але у неї є кілька корисних можливостей.

Усередині дужок можна перелічити через кому скільки завгодно значень — і текст у лапках, і імена змінних:

```
a = 6
b = 4
print("Сторони:", a, "і", b)
```
На екрані: `Сторони: 6 і 4`

Два правила, які плутають найчастіше. **Те, що в лапках, друкується буквально.** **Те, що без лапок, — це ім'я змінної, замість нього підставляється значення.**

```
print("a")     виведе   a
print(a)       виведе   6
```

І ще: між значеннями, перелічними через кому, Python сам ставить пробіл. Додатковий пробіл усередині лапок не потрібен.

Порожній рядок для краси виводять командою `print()` без нічого.

> 📝 **Команда виведення:** `print("текст", змінна, "текст")`
> У лапках — друкується як є. Без лапок — підставляється значення змінної.
> Між значеннями через кому Python сам ставить пробіл.

> ❓ **У змінній `s` лежить 5. Що виведуть рядки `print("s")` і `print(s)`?**
>
> *Очікуємо:* перший виведе літеру `s`, другий — число 5. Різницю робить лише наявність лапок.

### Блок 4. Будова будь-якої програми

Майже кожна програма, яку ви писатимете цього року, складається з трьох частин у такому порядку:

1. **Введення** — запитуємо в користувача вихідні дані (`input`)
2. **Опрацювання** — рахуємо потрібне (присвоювання)
3. **Виведення** — показуємо результат (`print`)

Ось повний приклад:

```
a = float(input("Довжина: "))
b = float(input("Ширина: "))
P = 2 * (a + b)
S = a * b
print("Периметр:", P)
print("Площа:", S)
```

Три рядки введення, два опрацювання, два виведення. Ця будова однакова для програми з п'яти рядків і для програми з п'яти тисяч.

> 📝 **Будова програми:** введення даних → опрацювання → виведення результату.

> ❓ **У програмі відразу після `input` стоїть `print`, а обчислень немає. Якої частини бракує?**
>
> *Очікуємо:* опрацювання — програма нічого не рахує, лише повторює введене.

print(int(a) + int(b))
```

## 7. Якщо лишився час

**Чому `input` не вгадує тип сам.** Здавалося б, Python міг би подивитись на введене й сам зрозуміти: `5` — це число, а `Оля` — текст. Так справді роблять деякі мови, і виходить із цього погано. Уявіть анкету, де користувач вводить номер телефона `0501234567`. Якщо мова «вгадає», що це число, вона відкине нуль на початку — і номер зіпсується. Або поштовий індекс `01001` перетвориться на `1001`. Тому Python не вгадує нічого: він завжди дає текст, а рішення приймає програміст.

**Чому в `print` не потрібні пробіли.** Якщо написати `print("Сума:", s)`, на екрані буде `Сума: 5` — з пробілом, хоч ви його не ставили. Python сам розділяє пробілом усе, що перелічене через кому. Це можна змінити: `print("2024", "09", "06", sep="-")` виведе `2024-09-06`, бо `sep` задає розділювач. Так зручно виводити дати або таблиці.
