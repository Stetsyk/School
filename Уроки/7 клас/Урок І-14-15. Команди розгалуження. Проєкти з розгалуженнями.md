## 2. Пояснення (10-12 хв)

### Блок 1. Умова — це питання з відповіддю «так» або «ні»

Щоб програма могла обрати, їй треба поставити питання, на яке є лише дві відповіді. Такі питання називають **умовами**, а записують їх знаками порівняння.

> 📝 **Знаки порівняння в Python**
>
> | Знак | Що означає | Приклад |
> | --- | --- | --- |
> | `>` | більше | `вік > 18` |
> | `<` | менше | `ціна < 100` |
> | `>=` | більше або дорівнює | `бал >= 10` |
> | `<=` | менше або дорівнює | `n <= 0` |
> | `==` | дорівнює | `пароль == "1234"` |
> | `!=` | не дорівнює | `відповідь != "так"` |

Одразу про найголовнішу пастку уроку. **Порівняння записують двома знаками рівності: `==`.** Один знак `=` — це присвоювання, тобто дія «поклади значення у змінну». Два знаки `==` — це питання «чи рівні вони?».

```
x = 5     кладемо 5 у змінну x
x == 5    питаємо: чи дорівнює x п'яти?
```

Результат будь-якої умови — одне з двох значень: `True` (правда) або `False` (неправда). Це окремий тип даних, він називається **логічний**, або `bool`.

Якщо `вік` дорівнює 13, то `вік > 18` дає `False`, а `вік < 18` дає `True`.

> 📝 Порівняння записують `==`, присвоювання — `=`.
> Результат умови — `True` (правда) або `False` (неправда).

> ❓ **У змінній `бал` лежить 8. Що дасть умова `бал == 8`, а що — `бал = 8`?**
>
> *Очікуємо:* перша дасть `True`, а друга взагалі не питання — це команда покласти 8 у змінну.

### Блок 2. Команда `if ... else`

Тепер сама команда розгалуження.

```
вік = int(input("Скільки тобі років? "))
if вік >= 18:
    print("Можна керувати автомобілем")
else:
    print("Ще зарано")
```

Читається просто: **якщо** (`if`) вік більший або рівний 18 — виконати перший блок, **інакше** (`else`) — виконати другий. Виконається завжди рівно один із двох, ніколи обидва.

У цьому записі є три речі, які не можна пропускати.

**Двокрапка.** Після умови й після `else` обов'язково стоїть `:`. Без неї Python зупиниться з помилкою.

**Відступ.** Рядки, які належать до гілки, зсунуті вправо на чотири пробіли. Саме відступ показує Python, де гілка починається і де закінчується. В інших мовах для цього ставлять дужки, у Python — відступи, і вони не для краси, а для роботи.

**Гілок рівно дві.** `if` без `else` буває, а `else` без `if` — ні.

У гілці може бути не один рядок, а скільки завгодно — головне, щоб усі мали однаковий відступ:

```
if вік >= 18:
    print("Можна керувати автомобілем")
    print("Не забудь пристебнутись")
else:
    print("Ще зарано")
    print("Зачекай", 18 - вік, "років")
```

> 📝 **Команда розгалуження:**
>
> ```
> if умова:
>     дії, якщо умова правдива
> else:
>     дії, якщо умова хибна
> ```
>
> Після умови й після `else` — двокрапка. Рядки гілок зсунуті вправо на 4 пробіли.

> ❓ **Скільки гілок виконається, якщо в програмі є `if` і `else`?**
>
> *Очікуємо:* рівно одна — або перша, або друга, ніколи обидві.

### Блок 3. Розгалуження без `else`

Іноді робити щось у другому випадку взагалі не потрібно. Тоді `else` просто не пишуть.

```
ціна = float(input("Ціна: "))
if ціна > 1000:
    print("Дорого! Подумай ще раз.")
print("Дякуємо за покупку")
```

Якщо ціна більша за 1000 — виведуться обидва рядки. Якщо ні — тільки останній. Зверніть увагу: останній рядок **без відступу**, тому він не належить до гілки й виконується завжди.

Такий запис називають **неповним розгалуженням**.

> 📝 **Неповне розгалуження** — `if` без `else`: дія виконується лише тоді, коли умова правдива, інакше не робиться нічого.

> ❓ **Останній рядок програми стоїть без відступу. Коли він виконається?**
>
> *Очікуємо:* завжди — він не належить до гілки, тому працює за будь-якої умови.

### Блок 4. Коли варіантів більше двох: `elif`

Що робити, якщо випадків не два, а три чи чотири? Наприклад, треба вивести оцінку за балом.

Для цього між `if` та `else` вставляють скільки завгодно гілок `elif` (скорочення від *else if* — «інакше якщо»):

```
бал = int(input("Бал: "))
if бал >= 10:
    print("Високий рівень")
elif бал >= 7:
    print("Достатній рівень")
elif бал >= 4:
    print("Середній рівень")
else:
    print("Початковий рівень")
```

Python перевіряє умови **згори вниз і зупиняється на першій правдивій**. Решту навіть не дивиться. Саме тому порядок тут дуже важливий: якби `бал >= 4` стояло першим, то бал 11 теж потрапив би в «середній рівень», бо 11 справді більше за 4.

> 📝 **`elif`** — додаткова гілка між `if` та `else`. Умови перевіряються згори вниз, виконується перша правдива.

> ❓ **Якщо в цій програмі поставити `бал >= 4` найпершою умовою, що виведе бал 11?**
>
> *Очікуємо:* «Середній рівень» — бо 11 більше за 4, і Python зупиниться на першій правдивій умові.

#### ✅ Відповіді до бонусів

**Бонус 1.** ```
a = float(input("a: "))
b = float(input("b: "))

максимум = a

Ідея, яку варто пояснити класу: замість того щоб перебирати всі варіанти, беремо перше число за «поточного чемпіона» і по черзі пробуємо його побити.

**Бонус 3.**
```
a = float(input("a: "))
b = float(input("b: "))
c = float(input("c: "))
if a < b + c and b < a + c and c < a + b:
    print("Трикутник існує")

Перевіряти треба **всі три** нерівності: якщо взяти сторони 1, 2 і 10, перша умова справдиться, а трикутника не буде. Слово `and` тут обов'язкове, бо потрібні одночасно всі умови.

**Бонус 4.** У найкращому випадку одну, якщо справдилася перша умова. У найгіршому п'ять, коли підходить остання гілка або жодна. Порядок важливий із двох причин. ## 7. Якщо лишився час

**Чому саме чотири пробіли.** Відступ у Python може бути будь-яким — хоч два пробіли, хоч вісім, головне, щоб усередині одного блоку він був однаковий. Але майже всі програмісти світу домовились писати чотири. Це записано в офіційному документі зі стилю Python, і всі редактори коду роблять так за замовчуванням. Причина проста: чужий код доводиться читати частіше, ніж писати свій, і однаковий вигляд коду економить усім час.

**Про табуляцію.** Найпідступніша помилка новачка — зсунути один рядок пробілами, а інший клавішею Tab. На екрані вони виглядають однаково, а для Python це різні відступи, і програма падає з дивною помилкою `IndentationError`. Правило одне: у межах файлу — або тільки пробіли, або тільки Tab. Більшість редакторів самі перетворюють Tab на чотири пробіли, і це найзручніший варіант.
