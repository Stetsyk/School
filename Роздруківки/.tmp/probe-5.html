Практичні завдання в зошиті

Завдання 1. Лінійний запис.

Перепишіть математичні вирази так, як їх треба записати в Python:

  1. 3·x + 5
  2. a² + b²
  3. дріб: чисельник (a + b), знаменник (a − b)
  4. 2·π·r (замість π взяти 3.14)
  5. дріб: чисельник (x − 1), знаменник 2·y

Завдання 2. Що виведе програма.

Простежте виконання кожного фрагмента по рядках і запишіть, що з'явиться на екрані:

а)

x = 4
y = 3
x = x + y
print(x)

б)

a = 10
b = a
a = 2
print(a, b)

в)

n = 5
n = n * n
n = n - 5
print(n)

Завдання 3. Таблиця значень.

Простежте програму по рядках і заповніть у зошиті таблицю: що лежить у кожній змінній після виконання кожного рядка. Порожню клітинку ставте, якщо змінної ще не існує.

a = 5
b = 2
a = a + b
b = a * b
a = a - 1
print(a, b)

Останнім рядком запишіть, що виведе print.

Далі та сама робота для другої програми, але додайте третій стовпець — тип кожної змінної (int чи float):

ціна = 4.5
кількість = 3
сума = ціна * кількість
print("До сплати:", сума)
