# Linux для шкільних ПК

## Що ставимо: Linux Mint XFCE

Обрав **Linux Mint XFCE** (64-bit) для старих шкільних комп'ютерів.

Чому саме вона:
- легка (XFCE), але з охайним інтерфейсом, схожим на Windows: панель знизу, меню в лівому кутку — учні розберуться одразу;
- в основі Ubuntu: `apt install` і всі інструкції для Ubuntu працюють так само;
- без Snap-пакетів (Firefox тощо запускаються швидше), а Flathub вбудований у «Менеджер програм» — Krita, Blender, TurboWarp ставляться в один клік;
- офіційний мінімум — 2 ГБ RAM, комфортно — від 4 ГБ.

Якщо комп'ютер зовсім слабкий (2 ГБ і менше): **Lubuntu** або **MX Linux**. Для дуже старих 32-бітних — лише **antiX**.

Mint ставиться тільки начисто з флешки (≈ 20–30 хв на ПК), тому спершу зберегти файли.

## Програми для уроків

- **Thonny** — Python.
- **Google Chrome** — потрібен для офлайн Google Документів і Таблиць (у Firefox офлайн-режиму немає). На Диску: Налаштування → увімкнути «Офлайн» + розширення Google Docs Offline. Вмикати, поки є інтернет.
- **LibreOffice** — уже є в Mint, працює повністю без інтернету, відкриває `.docx` / `.xlsx`.
- **Krita** — з Flathub; на слабких ПК невеликі полотна (до 1920 × 1080).
- **Scratch** — офлайн: **TurboWarp Desktop** (Flathub), відкриває звичайні проєкти Scratch; лише 64-bit.
- **Blender** — найважча програма. Новим версіям треба 8 ГБ RAM і відеокарту з OpenGL 4.3. На старих ПК — **Blender 3.6 LTS** (OpenGL 3.3) або 2.79 (OpenGL 2.1), портативний архів з blender.org. Перевірити відеокарту: `inxi -G`.
- На всіх ПК ставити **однакові версії** програм (найпростіше — усі через Flatpak) і **ярлики на робочому столі**, щоб учні просто клацали по іконці.

## Комп'ютери, де лишається Ubuntu

Щоб без перевстановлення вони виглядали як Mint XFCE — скрипт `ubuntu-to-xfce.sh` у цій папці:

```
sudo bash ubuntu-to-xfce.sh
sudo reboot
```

Що робить: ставить легкий XFCE (`xubuntu-core`) і екран входу LightDM, робить XFCE стандартним сеансом для всіх користувачів, переносить панель униз, як у Mint (кожному користувачеві один раз, під час першого входу в XFCE), вмикає zram (стиснена пам'ять) і вимикає зайві фонові служби (звіти про збої, індексатор файлів GNOME). Файли й програми лишаються. Старий робочий стіл Ubuntu нікуди не зникає — його можна вибрати на екрані входу, якщо щось піде не так. Спершу перевірити на одному ПК.

## Корисне для слабких ПК

- **zram** (на Mint): `sudo apt install zram-tools` — найкращий виграш на 2–4 ГБ.
- Браузер: 1–2 вкладки, без важких сайтів.
- **SSD** замість старого жорсткого диска — найбільше пришвидшення.
- Полегшення VS Code і Chrome — [[Полегшення VS Code і Chrome]].
