# Роздруківки практичних завдань у зошиті

Збирає з файлів уроків тільки блок **🕯️ У зошиті**, кожен урок починає з
нової сторінки A4 (кеглем 14 pt) і робить **один PDF на друк**. Внизу
кожної сторінки стоїть номер у вигляді «3 / 12». Готове лягає в теку
`Роздруківки/`. Якщо потрібен ще й Word-файл, додається ключ `--docx`
— там номер сторінки йде нижнім колонтитулом.

## Як запускати

З кореня теки School:

```bash
python3 "Tools/zoshyt/zoshyt.py" "5 клас 2-3 урок" "6 клас 2-3" "7 клас 11-12" "8 клас 2-3" "9 клас 2-4" "пайтон 1-5"
```

З теки самого скрипта — так само, тільки коротше:

```bash
cd "Tools/zoshyt"
python3 zoshyt.py "5 клас 2-3 урок" "9 клас 2-4" "пайтон 1-5"
```

Запускати можна звідки завгодно: скрипт знаходить теку School від свого
власного розташування, а не від поточного каталогу.

Формат запиту вільний:

| Що друкуємо | Тека | Приклади запиту |
| --- | --- | --- |
| Класи 5–9 | `Уроки/N клас` | `5 клас 2-3 урок`, `7 клас 11`, `6 клас ІІ 4-6` |
| Курс Python | `Уроки/Пайтон` | `пайтон 1-5`, `python 13`, `пайтон урок 7` |

Слова «клас» і «урок» можна не писати, семестр за замовчуванням І. У курсі
Python семестрів і класів немає — тільки наскрізний номер уроку. В одному
запуску можна змішувати класи й Python; уроки Python ідуть у роздруківці
першими.

**Спарені уроки не ріжуться навпіл.** Якщо попросити `9 клас 2-4`, а уроки
лежать як `І-02-03` і `І-04-05`, у роздруківку піде 2-5. Скрипт про це пише.

## Ключі

| Ключ | Що робить |
| --- | --- |
| `-o НАЗВА` | своя назва файлів замість автоматичної |
| `--відповіді` | додати блок ✅ — примірник для себе, не для класу |
| `--підпис` | рядок «Прізвище / Дата» вгорі сторінки |
| `--кегль 12` | інший розмір шрифту (типово 14) |
| `--docx` | зробити ще й `.docx` (за замовчуванням тільки PDF) |
| `--лише-docx` | зробити лише `.docx`, без PDF |

## Кегль

Увесь текст друкується кеглем **14 pt**. Розміру ніхто не підбирає, тому
Chrome стартує один раз на весь документ і скрипт відпрацьовує за кілька
секунд навіть на весь курс. Якщо завдань у уроці багато, він займе дві
сторінки — це нормально, номери сторінок унизу це враховують.

Потрібен інший розмір — `--кегль 12` (чи будь-яке число). Діє на всі уроки
одразу, окремо для одного уроку кегль не задається.

## Що має бути в уроці

Блок завдань обгорнутий маркерами, які в Obsidian не видно:

```markdown
### 🕯️ У зошиті
<!-- ЗОШИТ:ПОЧАТОК -->
**Завдання 1 (обов'язкове). …**
…
<!-- ЗОШИТ:КІНЕЦЬ -->

#### ✅ Відповіді та орієнтири
```

Маркерів у файлі може бути кілька пар — усі вони збираються по порядку
(так зроблено в уроці з практичною роботою у 8 класі). Урок без маркерів
скрипт пропускає й пише про це.

Файли уроків мають називатися:

- класи 5–9 — `Урок І-11. Назва.md` (семестр `І`/`ІІ`, наскрізний номер
  уроку в семестрі з двох цифр; спарений — `Урок І-10-11. Назва.md`);
- курс Python — `Урок 07. Назва.md` у теці `Уроки/Пайтон`.

## Що потрібно на комп'ютері

- **Google Chrome** — для PDF, тобто завжди.
- **pandoc** — тільки якщо просите `.docx` (`brew install pandoc`).

Сторонніх бібліотек Python немає, вистачає системного `python3`.

Chrome на macOS 12 у headless-режимі малює сторінку правильно, але сам не
завершується — скрипт це знає й вбиває процес, щойно PDF дописано.
