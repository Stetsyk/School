# Принтер Epson Stylus SX430W (Wi-Fi)

Ставити треба **рідний драйвер Epson**, а не Gutenprint. Принтер розуміє тільки мову ESC/P-R, тому Gutenprint друкує чисті аркуші, хоча голівка справна і завдання проходить без помилок.

Драйвер: сторінка підтримки Epson → Stylus SX430W → macOS → «Driver» (dmg ~93 МБ).
https://www.epson.eu/en_EU/support/sc/epson-stylus-sx430w/s/s1013

Принтер тільки на 2.4 ГГц, мережу з `_5G` у назві він не побачить. Після установки драйвера додати через Системні параметри → Принтери та сканери → «+», принтер видно по Bonjour як `EPSON0C01DF.local`, порт 9100.

Якщо друкує чисто — перевір тест дюз кнопками на принтері. Сітка друкується → винен драйвер, а не голівка.

## Робочі параметри друку

Голівка слабка, тому на звичайних налаштуваннях друкує блідо або смугами. Що працює:

- Тип носія: **Epson Premium Glossy** (навіть на звичайному папері) — принтер кладе більше чорнила і йде повільнішим проходом
- Колір: **чорно-білий**, кольорові сопла в поганому стані
- Якість: Standard, папір A4, подача Standard з полями

Ці значення вже прописані в черзі друку як стандартні, тому діють у всіх програмах. Разово змінити можна в діалозі друку.

## Друк з термінала

Черга називається `Epson_SX430W`. Тип носія, чорно-білий режим і A4 уже стоять за замовчуванням, повторювати їх не треба.

Приклад, перші 13 сторінок, 3 копії:

```bash
lp -d Epson_SX430W -n 3 -P 1-13 -o fit-to-page -o outputorder=normal -o number-up=2 
  "/Users/oleksiistetsyk/Library/Mobile Documents/iCloud~md~obsidian/Documents/School/Роздруківки/Зошит python-1-40.pdf"
```
`-o outputorder=normal`
`collate=true` дає порядок 1-13, потім знову 1-13, а не три копії кожної сторінки підряд.

## Якщо щось пішло не так

```bash
lpstat -p Epson_SX430W      # стан принтера
lpstat -o Epson_SX430W      # що в черзі
cancel -a Epson_SX430W      # скасувати всі завдання
cupsenable Epson_SX430W     # зняти блокування черги
```

**Communication error** зазвичай означає, що принтер вимкнувся або пропав з Wi-Fi посеред завдання. CUPS пише `Broken pipe` і блокує чергу. Лікується командою `cupsenable`, завдання після цього друкується саме.

## Щоб мак не заснув під час довгого друку

Відкрите вікно черги друку сон **не** блокує. Потрібна окрема команда. Ця тримає мак розбудженим рівно доти, доки в черзі є завдання, і завершується сама після останньої сторінки:

```bash
caffeinate -is bash -c 'until [ -z "$(lpstat -o Epson_SX430W 2>/dev/null)" ]; do sleep 30; done'
```

Зупинити достроково:

```bash
pkill -f "caffeinate -is"
```

Перевірити, чи блокування активне:

```bash
pmset -g assertions | grep PreventUserIdleSystemSleep
```

Кришку закривати не можна, це присипляє мак попри блокування. Екран гасне сам, на друк це не впливає.

## Протокол зʼєднання

Черга працює через **LPD** (`lpd://EPSON0C01DF.local/auto`), а не через прямий порт 9100.

Порт 9100 у цього принтера односеансний: драйвер тримає одне зʼєднання і по ньому ж чекає відповідей про стан. На важких сторінках принтер не встигає відповісти, драйвер вважає звʼязок втраченим і показує **Communication error**, а завдання зависає на середині. LPD передає завдання одним шматком без постійного каналу стану, тому таких обривів немає.

Якщо помилка колись повернеться, наступний крок це закріпити за принтером постійну IP-адресу в роутері. Адреса вже змінювалася сама.
